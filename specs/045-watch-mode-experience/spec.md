# 045 — 观影模式体验设计

> 状态：设计稿待确认 ｜ 2026-11-24 ｜ 依据：用户“观影模式效果不好，要更细节、体验更好的版本”
> 本规格先定义体验，再进入实现；`frontend/` 暂不改动。目标稿：`docs/design/watch-mode/mock-{desktop,mobile,empty}.png`。

## 1. 问题诊断（当前实现）

| 现象 | 数据/证据 | 影响 |
|---|---|---|
| 视频下方大片死黑 | 1440×900：视频约 1059×595，下方约 200px 空白 | 像“嵌入了一块的网页”，不是影院 |
| 两层 chrome | 顶栏 + LearningHeader 共约 96px | 观影模式没有真正进入沉浸 |
| 字幕通栏黑带 | 全宽不透明带，压在画面下缘 | 割裂画面，且与控件抢安全区 |
| 词条栏空 | 345px 栏内只有 1 行词 | 大面积空白比没有更干扰 |
| 退出按钮浮层 | “退出观影”压在画面右下/字幕附近 | 打断观看，层级错误 |
| 移动端失衡 | 375：视频 343×193，字幕占近一半，下方 500px 空 | 手机端基本不可用 |
| 无状态设计 | 无分析=空白；无词=空白 | 用户不知道是坏了还是没数据 |

## 2. 体验目标

**一句话**：像在看电影，学习工具安静地待在旁边；想学时一伸手就够得到，不想学时它不抢画面。

四个可验证目标：

1. **沉浸**：除画面/字幕/必要控制外，没有常驻 chrome。
2. **可读**：连续看 30 分钟不累；字幕不遮控件、不裁切。
3. **可学**：当前句的词/语言点随手可见；收藏/已掌握一键完成。
4. **不打断**：任何分析加载/失败都不阻塞播放；空态不制造焦虑。

## 3. 设计原则

1. **画面第一，控件第二**：chrome 在指针静止 2.5s 后淡出；移动/按键再出现。
2. **渐进披露**：默认只有字幕 + 当前句词条；历史/操作/设置按需展开。
3. **一个模式，一个主动作**：观影按钮是唯一入口；不再有独立全屏按钮。
4. **黑边是构图**：用环境光/模糊背景填充，而不是留死黑。
5. **不假装**：无分析/无词条时给明确、克制的状态，不画假内容。
6. **连续性**：播放位置、观影偏好、词条滚动位置在会话内不丢；跨视频重置词条历史。
7. **可调**：字幕字号/位置/单双语、词条栏开合，是学习工具的基本控制。

## 4. 桌面（≥1280）

### 4.1 壳层

```
┌───────────────────────────────────────────────┬──────────────┐
│ [返回] 标题 · 观影模式          [设置] [退出] │  滚动词条     │
│                                               │              │
│           16:9 画面（居中，环境光）           │  当前句目标   │
│                                               │  ─────────   │
│   ┌──── 当前句字幕（英文主/中文辅）────┐      │  历史（淡）   │
│                                               │              │
│  ▶  ─────●────────  12:34 / 18:20  1.0x  CC  │              │
└───────────────────────────────────────────────┴──────────────┘
```

- **移除**普通顶栏与 LearningHeader 常驻；只保留浮层顶部条（返回、标题、设置、退出），2.5s 后淡出。
- 舞台占满剩余视口；视频 `object-fit: contain`，16:9 居中；上下黑边用低饱和环境光/模糊画面填充。
- 右侧词条栏 **360px**（`clamp(340px, 25vw, 380px)`），与画面之间 1px 分隔线，不抢画面。
- 控制条浮在画面下缘，自动隐藏；不占布局高度。
- 退出不再用画面中央的按钮；退出在顶部浮层，`Esc` 分层：先退全屏，再退观影。

### 4.2 字幕

- 英文主内容：`clamp(20px, 2.1cqi, 32px)`，600；中文辅助：`clamp(15px, 1.7cqi, 24px)`，400。
- 最大 2 行，行宽 `min(68ch, 86%)`；`text-wrap: balance`。
- 背景：下缘渐变 scrim（透明→`rgba(0,0,0,.72)`），**不是**通栏实色带；左右留 48px 安全边。
- 距画面下缘 8–10%，避开进度条/控件；字幕不与控制条重叠。
- 换句 120ms 淡入淡出；`prefers-reduced-motion` 直切。
- 字幕不可点击（避免误触 iframe）；未来可做“点词查词”再单独评估。

### 4.3 词条栏

- 标题「滚动词条」+ 当前句词数（小号、低对比）。
- 当前句目标置顶；历史向下顺延，旧条目 `opacity: .55`，越旧越淡（最多 30 句）。
- 每条：词/短语（amber/sky）+ 释义；**无**分组标题、kind 徽章、整句上文、边框、分割线。
- 操作在 hover/focus 时出现：☆ 收藏、✓ 已掌握、🔊 发音（若已有能力）；触屏用长按/点按行尾。
- 当前句左侧 2px 竖线或极轻底色标记，不使用“当前句”文字。
- 空句不生成条目；当前句无词时保留历史，不显示“本句无生词”。
- 无分析时：栏内只留一条说明 + 「生成词条」按钮，不铺满空白；生成中显示骨架。

### 4.4 控制条

- 播放/暂停、±5s、进度、时间、倍速、字幕开关、设置、全屏/退出全屏、退出观影。
- 自动隐藏；鼠标移动、键盘、触摸出现；焦点在控件时不隐藏。
- 键盘：`Space` 播放/暂停；`←/→` ±5s；`J/L` ±10s；`C` 字幕；`F` 全屏；`W` 退出观影；`Esc` 退全屏/退观影。
- 播放器 iframe 的控件不可依赖；外层控制条是唯一控制面。

## 5. 移动端（<768）

```
┌─────────────────────────┐
│ ‹  标题            ⋯    │ 44px
├─────────────────────────┤
│      16:9 视频          │
│   英文字幕（主）         │
│   中文字幕（辅）         │
├─────────────────────────┤
│ ▶  ───────  12:34  CC  ⛶│ 控制条（常驻）
├─────────────────────────┤
│ ═══ 滚动词条（抽屉）     │
│ habits          习惯  ☆ │
│ take off        起飞  ☆ │
│ ...（上拉看历史）        │
└─────────────────────────┘
```

- 顶部 44px 极简栏：返回、标题、更多；不显示普通 tab。
- 视频 16:9 固定，左右 8px；字幕在画面内下缘，英文 17–24、中文 14–18。
- 控制条在视频下方**常驻**（移动端自动隐藏体验差）；进度可拖动。
- 词条用**底部抽屉**：半开高度 280–320px；拖拽手柄；上拉看历史；不覆盖视频；默认展开（手机屏幕小，不展开等于没有）。
- 退出在顶部栏“更多”或返回；全屏按钮在控制条。
- 安全区：底部 `env(safe-area-inset-bottom)`；字幕避开 Home indicator。

## 6. 空态/加载/失败/登录

| 状态 | 表现 | 不做什么 |
|---|---|---|
| 分析加载中 | 词条栏 2 行骨架；播放不受影响 | 不遮画面、不弹 toast |
| 无分析 | 栏内说明「本片还没有词条」+ 生成按钮；视频正常 | 不铺满空白、不显示“本句无生词” |
| 分析失败 | 一句说明 + 重试；保留已缓存内容（若有） | 不阻塞播放、不自动重试刷屏 |
| 未登录 | 说明 + 登录；视频可看 | 不弹全屏登录墙 |
| 当前句无词 | 保留历史，不显示占位 | 不留白块、不显示“本句无生词” |
| 游客 | 不请求 AI 分析；提示登录后生成 | 不假装有词条 |

## 7. 视觉 token

- 背景：`#08090b`；浮层：`bg-app/80 + backdrop-blur`；分隔线：`white/8`。
- 文字：主 `fg-primary`、次 `fg-secondary`、弱 `fg-muted`；词 amber `#fbbf24`；语言点 sky `#7dd3fc`。
- 圆角：画面 18px、浮层 14px、抽屉 18px；间距 4/8/12/16/24。
- 不使用纯白大块、不使用彩色渐变按钮；强调色只用于学习目标。

## 8. 验收（体验，不只是元素存在）

1. **5 秒测试**：截图给未接触产品的人，能说出“这是看电影学英语”。
2. **遮挡测试**：字幕/控制/退出/词条在 375、768、1440、1920 互不遮挡。
3. **连续观看 10 分钟**：无需滚动页面；控制条自动隐藏；词条自动跟句。
4. **状态测试**：加载/无分析/失败/未登录/空句都有明确表现，视频始终可播。
5. **键盘/触摸**：快捷键可用；375 触摸目标 ≥44px。
6. **性能**：首句字幕不等待分析；分析不产生新 AI 调用；切换句子无布局跳动。
7. **指标**：首句可读时间、词条打开率、收藏率、10 分钟留存、退出率（上线后埋点）。

## 9. 实施顺序（设计确认后）

1. 壳层/舞台 + 顶部浮层 + 桌面/移动布局（不碰数据）
2. 字幕排版/字号/位置/设置
3. 词条栏/抽屉 + 收藏/已掌握
4. 控制条/键盘/状态
5. 空态/加载/失败 + 可访问性
6. 视觉 QA + 375/768/1440/1920 + 连续观看测试

## 10. 非目标（本期）

- 画中画、投屏、字幕下载
- 逐词 karaoke 高亮（后续）
