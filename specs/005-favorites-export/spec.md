# 规格：单词本与导出

**状态：** 已实现（M1 ④ 按条 API：2026-11-15；生词折叠与出处：2026-11-16；独立「单词本」页面：2026-11-17；短语 tab：2026-11-17；全词表编辑模式：2026-11-23；编辑态全选（按筛选结果跨页）：2026-11-23；已掌握默认加入时间 + 全词表导出：2026-11-23；所有词表手风琴：2026-11-23）｜ **对应代码：** `backend/routes_user.py`（`/api/favorites`）、`backend/routes_vocabulary.py`（词表目录/短语/分页/等级）、`backend/storage.py`（路径 + 墓碑文件）、`backend/vocabulary.py`、`frontend/src/lib/favorites.ts`、`frontend/src/lib/vocabulary.ts`、`frontend/src/lib/favoriteSource.ts`、`frontend/src/components/VocabularyBookScreen.tsx`、`frontend/src/App.tsx`、`frontend/src/lib/exporter.ts`

## 目标
打通学习闭环的最后一环——把"看过/查过"沉淀成"可复习"。单词不能只是躺在收藏里：要能按 CEFR 与考试词表浏览、按中文遮挡自测、再一键导出到真正的复习工具。

## 用户故事
- 作为用户，我想**星标**重要的生词，连同它们的来源语境一起存下来。
- 作为用户，我想在独立的「单词本」里看到**我的收藏**（原「我的单词」，2026-11-22 改名；路由不变），并展开查看它的 CEFR 等级、出处与收藏时间；不在词表里的词诚实显示 `C1+`。
- 作为用户，我想按 **CEFR A1–C2 + GRE + CET4 + CET6** 浏览词表，搜索单词并看到音标、中文释义与等级。
- 作为用户，我想在「短语」tab 里按等级与类型浏览人工精选的短语动词、习语和固定搭配，展开看例句、类型说明与用法笔记。
- 作为用户，我想**隐藏中文**背词；点某一行临时显示释义，再点收起；这个偏好下次打开仍然记得。
- 作为用户，我想把收藏的单词**导出到 Anki** 做间隔重复，或导成 CSV 自己整理。
- 作为同时开两个标签页/两台设备的用户，我在一边加/删收藏，另一边不会把整份收藏覆盖掉。

## 功能需求
### 收藏数据（不变）
- **必须**：可收藏两类——整句、单词（生词）；都带来源句、视频/文章、时间点。
- **必须**：收藏持久化到后端（每用户 `favorites.json`），后端不可用时退回 localStorage。
- **必须**：按条写入（`POST /api/favorites`、`DELETE /api/favorites/{id}`），不再由前端发整文件 PUT；旧 `PUT /api/favorites` 只作兼容保留。
- **必须**：同一条收藏有稳定 `id`；重复 POST 幂等（按 id 或内容指纹去重）；删除不存在的收藏返回 `404`。
- **必须**：旧 `favorites.json` 里没有 `id` 的记录读取时补稳定 `id`，不丢数据、不在 GET 时改写文件。
- **必须**：并发安全——同一用户的读-改-写用文件锁串行化，并用 tmp + `os.replace` 原子落盘。
- **必须**（2026-11-16 起）：收藏写入时带出处 `meta.source_kind`（`video` / `local_show` / `article` / `library_article` / `sentence_pack` / `book` / `imported_book`）、`source_ref`、`source_title`；后端按“未知字段原样保留”落盘，GET 顶层返回。
- **应当**：没有 `source_*` 的旧收藏按 `videoId` 启发式推断（11 位 → 视频；`sentence-pack-L*` → 句子精背；其他长 id → 文章），标题未知时显示「来源未知」且不可点。

### 单词本页面（2026-11-17）
- **必须**：独立整页路由 `#/profile/vocabulary`（旧 `#/profile/favorites` 作为兼容别名，自动改写为新路由）；顶栏标题「单词本」+ 返回。
- **必须**（2026-11-23 P1-16 起）：单词本入口统一收敛到 AppShell 顶栏 `topbar-wordbook`（计数=生词数，与浏览界面同一组件/位置），阅读器、免费资源视频、本地视频与浏览页一致；阅读器 header actions、`LearningHeader` 及本地视频页内的单词本入口全部删除（`ReadingVocabButton` 组件随之删除）。侧边栏快捷入口「单词本」与个人页「我的收藏」行保留；这些入口都打开独立页面，**不再弹 FavoritesModal**（组件已删除）。
- **必须**：Tabs 顺序 `我的收藏 / 已掌握 / 短语 / CEFR 词表 / GRE / CET4 / CET6`（2026-11-22 P0-10 起「我的单词」显示名为「我的收藏」）；词表 tab 数量来自 `GET /api/vocabulary/lists`；收藏数量在顶栏/侧边栏显示（只数生词）。
- **必须**：**我的收藏**只列 `favorites` 中 `type=vocabulary`（句子/分享卡不列入），默认一行（单词 + IPA + 中文释义）；展开区只放完整释义、CEFR 徽章、来源（可跳回视频/本地剧集/文章/免费文章/句子精背/公版书/导入书）与收藏时间，**不提供任何加入收藏/取消收藏按钮**——收藏与取消收藏都只由行尾星标发起（唯一入口），词表行不提供「加入我的单词」。计数=该收藏列表长度，不做减法（ADR-0001）。等级走 `GET /api/vocabulary/level`（每批 ≤100），不在词表或非法 token 显示 `C1+`。行尾同时有**已掌握对勾**（P0-10）：仅图标、`aria-pressed`，点击 PATCH mastered 并把词移入「已掌握」（写路径移除收藏）。
- **必须**：**词表**支持服务端搜索（`q`，300ms 防抖）、每页 50、分页；每行 word / phonetic / translation / CEFR 徽章。
- **必须**：**短语**（2026-11-17）：tab 位于「我的收藏」之后，数量取自 `/lists` 的 `phrases.count`；行内显示 headword、类型徽章（短语动词/习语/固定搭配）、中文释义、CEFR 徽章；默认单行/两行，展开懒加载 `/phrases/{id}` 显示例句、类型说明、来源（人工精选）、license 与用法笔记；点击行展开/收起。
- **必须**：短语 tab 的服务端搜索（`q`，300ms 防抖）、等级筛选（全部/A2/B1/B2/C1）、类型筛选（全部/短语动词/习语/固定搭配）、每页 50 与页码/上一页/下一页；加载/空/错误重试。短语的列表/搜索/筛选/分页状态与单词表完全独立；切 tab 重置分页。
- **必须**：短语 CEFR 是教学近似值（`approximate:true`）：徽章 title 与列表说明都标注「近似、非官方」，筛选不提供 C2（数据无 C2）。
- **必须**：「隐藏中文」全局开关：隐藏后只显示单词（+ 音标与等级），点击行临时显示中文，再点收起；偏好写 localStorage（`yt_bilingual_vocab_hide_zh`）并跨刷新记忆。短语同样复用该开关：隐藏时行内只留 headword（+ 类型与等级），点击行临时显示释义，展开详情时中文类型说明与用法笔记也保持隐藏。
- **必须**：C2 `available:false` 时 tab 禁用并显示「C2 词表暂未建模」；**不请求** C2 词表、不拿空表冒充数据、不用 GRE 冒充 C2。
- **必须**：加载/空态/错误重试；导出 Anki TSV / CSV 只导出「我的收藏」（生词），不再混入句子。
- **必须**：中越 i18n 文案与 placeholder 对齐；桌面表格化、375px 单列不横向溢出。

### v1.1 交互升级（本轮最小版）

- **必须**：**已掌握**——词条浮层保留「我已掌握」文字动作；**单词本所有词表的默认行**都提供**对勾图标**（P0-10，无文字），标记后从「我的收藏」移入独立的「**已掌握**」词表（见下一条），可撤销；撤销掌握只清除 `word_states.mastered`，**不回填收藏**（用户要再显式点星收藏）；数据与复习共用 `word_states.mastered`（见 specs/013），不在收藏里另存一份。游客用本地 `localStorage` 忽略表实现同样效果，但**不叫「已掌握」**（叫「我会了」），不上传服务端。
- **必须（P0-13）**：标记已掌握时把**行内中文释义**传给 `PATCH /api/review/words`，由后端在 `word_states.definition` 为空时写入快照（仅空时写、不覆盖；`mastered=false` 不写）。收藏行取 `zh_text` 拆分后的中文释义（不含音标），内置词表/短语/自定义词表取行内 `translation`；无释义时不传。这样从「我的收藏」移入「已掌握」后释义列不丢；成功后仍执行 DELETE 收藏，失败回滚与行内错误行为不变。
- **必须（2026-11-22 复习 UI 暂停启用）**：单词本里与复习相关的入口**隐藏**——「加入复习」按钮、
  学习状态筛选（新词/学习中/复习中/已暂停）；「已掌握」与行尾星标保留。后端数据不变。
- **必须（2026-11-22 修订）**：**「已掌握」是独立词表 tab**，与「我的收藏」并列，**不是**同一页内的分组/分段切换。tab 顺序：`我的收藏 / 已掌握 / 短语 / CEFR 词表 / GRE / CET4 / CET6`；游客的 tab 名为「我会了」。
- **必须**：已掌握 tab **复用内置词表（GRE / CET-4）的表格格式**——列「单词（含音标）/ 释义 / CEFR 徽章」，桌面三列、375px 单列；支持「隐藏中文」（点行临时显示）；客户端分页每页 50（服务端已掌握列表上限 200）。数据源只有 `word_states.mastered=1`，计数=`words.length`；释义优先 `word_states.definition` 快照，历史遗留的同词收藏记录只作释义回退、**不代表已收藏**，皆无则显示 `—`；CEFR 批量走 `GET /api/vocabulary/level`。
- **应当**：已掌握行的**默认行对勾**（按下态=已掌握）就是撤销入口，否则无法从该页移回；**不再有展开区文字撤销动作**；撤销乐观更新、失败回滚并 toast。
- **必须**：「我的收藏」不再混入已掌握词（两个列表互斥）；已掌握 tab 的加载/空/错误三态齐全（错误可重试，失败不当空态）。
- **必须**：**来源**——每行显示**最后一次**收藏/加入时的来源链接（`meta.source_kind` + `source_ref` + `source_title`）；同词同来源再次收藏时更新来源与时间，不新增重复行；`context_en/context_zh` 旧数据保留但**不再展示**。
- **必须**：**排序**——「我的收藏」支持按 加入时间 / 见过次数 / 难度 排序（默认加入时间倒序）；难度批量走 `GET /api/vocabulary/level`，见过次数走新增的 `GET /api/vocabulary/seen`。
- **必须**：**筛选**——类型（词/短语）、来源（按 `source_kind`）、未掌握；与排序可叠加；空结果给空态而不是空白。
- **必须**：**加词入口**——词条浮层主入口 + 收藏行次入口，调用 `POST /api/review/words` 并带来源；交互与验收见 specs/013。
- **必须**：三态齐全与错误可重试；i18n 中越对齐；375px 单列不溢出。

### 已掌握与收藏互斥（2026-11-22 补充）

- **必须**：**「已掌握」不是收藏**——标记已掌握时同时**移除该词的收藏**；**收藏计数=
  收藏列表长度**（`favorites(type=vocabulary).length`），不做 `favorites − mastered` 减法，
  也不在读路径过滤；导出 Anki/CSV 与计数同源。
- **必须**：已掌握列表的数据源是 `word_states.mastered=1`（不是收藏）；行内释义优先
  `word_states.definition` 快照，历史遗留的同词收藏仅作释义回退，皆无显示 `—`。
- **必须**：已掌握行的星标位置不显示「已收藏」状态（不可把已掌握词伪装成收藏），固定词表中已掌握行的星标禁用；
  撤销已掌握后该词**不自动回到收藏**，用户可再点星收藏。
- **必须（P0-13）**：已掌握列表的释义来自 `word_states.definition` 快照；旧数据里该列为空的 4 条
  （affordability / intimately / thorny / ecstacy）由 `scripts/backfill_mastered_definitions.py`
  从 reconcile 备份中的原收藏 `zh_text` 回填：默认 dry-run 只列清单、零写入；`--apply --yes --user-id`
  先写备份 + JSONL 审计再只填空、不覆盖；`--check` 要求空释义=0；`--rollback` 可恢复。
- 验收：计数等于收藏列表长度；标记已掌握后计数 -1（写路径删除该收藏）；撤销掌握不回填收藏
  （计数不变）；已掌握 tab 仍能看图/看释义。

### 词表手风琴（2026-11-23，P1-22）

**目标：任何词表同一时刻只展开一行，展开区不再堆叠。**

- **必须**：**我的收藏 / 已掌握 / 内置词表（CEFR·GRE·CET4·CET6）/ 自定义词表**共用同一份
  展开状态（单一「当前展开行 id」，`null` = 全部收起）：展开 A 后再展开 B，A 自动收起；
  再点当前展开行收起；同一时刻最多一行有展开区。
- **必须**：**短语**同样是单开手风琴，且详情异步加载跟随当前行：切到另一行时取消上一行的
  未完成请求并丢弃它的详情缓存；收起当前行清空该行详情；换页/搜索/筛选/切 tab 一律收起并清空
  缓存，不出现过期详情串到别的行。
- **必须**：**切 tab 清空**——任何 tab 切换都收起当前展开行（词表与短语各一次）；编辑模式
  仍不展开（点击行 = 选择）；星标、已掌握对勾、展开区内容/操作、行底色与 testid 全部不变。
- **必须**：词族（specs/041）已有的单开手风琴保持不变，并与上述规则一致（切 tab 收起）。
- 验收：`wordbook-v12` / `mastered-tab` / `custom-wordlists` / `word-family` 四个脚本分别断言
  「单开、切换自动收起、再点收起、切 tab 清空」，各跑 2 次 PASS；`tsc -b` / `build` /
  `check:i18n` / `gate-receipt` 绿；1440/375 无回归。

### 统一词表 UI（2026-11-22 重设计）

**目标：所有词表（我的收藏 / 已掌握 / 内置词表 / 自定义词表）共用同一行与工具栏，减少分心。**

- **必须**：默认每个词**一行**（桌面 ≥md 单行；375px 一个词仍占一项，内部两行排布），
  从左到右：原词 / 音标（无则留空）/ 释义（单行省略）/ 发音 / 等级徽章 / 收藏星标 / 已掌握圆形勾选 / 展开箭头；
  「见过次数 `×N`」**仅我的收藏**显示。
- **必须**：列对齐与格式统一——释义一律左对齐；音标统一 `/.../`；等级统一 `LevelBadge`；
  收藏统一 `Star`（实心=已收藏，点击切换）；已掌握统一**圆形勾选按钮**（ghost 图标按钮、44px 热区、`aria-pressed`），不可因数据缺失改变行高。
- **必须（P0-12）**：已掌握开关是**同一外形的圆 + 勾双态开关**，只靠填充/颜色区分，**不得出现裸勾（Check）**：
  - **未掌握**：空心圆，`border-line-*` 边框 + 中性灰勾（`text-fg-muted`），hover 时圆底/勾色有反馈；
  - **已掌握**：`success` 浅绿底（`bg-success/15`）+ `border-success/40` 圆 + 绿色勾（`text-success-fg`），视觉上“已选中”；
  - 两态共用同一 `Check` glyph 与圆形尺寸；44px 热区、`aria-pressed`、`aria-label`（已掌握/取消已掌握）与行内错误行为不变；只用 design token，不引入 hex。
- **必须（P0-10）**：固定词表（内置 CEFR/GRE/CET4/CET6、短语、自定义词表）的行底色：已掌握 `bg-success/10`、收藏 `bg-warning/10`、无状态默认；互斥时已掌握优先；「我的收藏」「已掌握」两个 tab 不加底色。只用 design token，不引入 hex，不改变行高/对齐/hover。
- **必须**：行尾展开区（`⌄`）放完整释义（多义项）、来源链接与操作（**不含已掌握文字动作**，「我已掌握/取消已掌握」只由行尾对勾承担）；
  **展开区不提供任何加入收藏按钮（含「加入我的单词」与「已加入」disabled 变体）**——
  收藏与取消收藏都只由行尾星标承担（唯一入口）；
  展开不引发整表重排抖动。
- **必须**：工具栏统一为「搜索框 + 排序选择器 + 筛选选择器」；排序与筛选各自一个下拉/弹层，
  按钮显示当前值（如「排序：字母」）；不再出现成排 chips 或分段控件。
  - 排序按词表能力：加入时间 / 见过次数 / 难度 / 字母
  - 筛选按词表能力：类型 / 来源 / 未掌握 / 等级；筛选支持多条件（弹层内保持展开）
- **必须**：分页统一——每页条数可选 `20/50/100`、上一页/下一页、页码与**跳转输入框**；
  我的收藏/已掌握/自定义词表客户端分页；内置词表服务端分页。
### 编辑模式与批量操作矩阵（2026-11-23，P0-14）

  展开区不展开，确保批量操作不会误触行级写操作。选中行有独立底色（`bg-state-selected`）。
- **必须**：**逐条执行与失败语义**——批量操作逐条请求；成功项移出选择，失败项保留选中 +
  行内错误 + 底部「N 项失败」汇总；操作进行中所有操作按钮/checkbox/完成按钮禁用（不重复提交）。

- **必须**：自定义词表删除按条执行并弹出 ConfirmDialog；每删除一条就用服务端返回的 `itemCount`
  更新 tab 徽标与头部计数；失败条目保留在选中态且不删除本地行。词表重命名仍在头部菜单；
  加入复习不在本卡范围（复习 UI 暂停时全部隐藏）。

- **必须**：短语表沿用同一行结构，可多一个「类型」徽章（短语动词/习语/固定搭配），并同样有已掌握对勾与行底色。
- 验收：五个列表（我的收藏、已掌握、CEFR/GRE/CET4/CET6、自定义、短语）行结构一致；
  1440 单行、375 无横向溢出；星标/已掌握对勾/发音/展开/编辑/分页均可用；中越 i18n 对齐；G1 P0=0；固定词表三态底色正确。

### 编辑态全选（2026-11-23，P0-15）

- **必须**：编辑态的表头出现**三态全选 checkbox**（未选 / 部分 indeterminate / 全选），默认不选；
  退出编辑或切换 tab 都清空选择并移除该控件；非编辑态不渲染全选 checkbox。
- **必须**：**全选 = 当前搜索 + 筛选 + 排序命中的全部结果（跨页）**，不只是当前页：
  - 客户端分页列表（我的收藏 / 已掌握 / 自定义词表，均一次性加载全部条目）直接选中当前筛选排序后的全部行；

    循环拉取全部分页，合并 rows 后全选；拉取期间显示 loading 并禁用全选/批量；
    拉取失败时**保留原有选择**，用 toast + 行内错误说明，不把部分页伪装成“已全选”。
- **必须**：底部操作条显示「已选 N / 结果 M」；部分选中时表头为 indeterminate；
  已全选时再次点全选 = 清空选择（清除选择），仍保持编辑态。
- **必须**：**跨页批量操作**——批量执行使用 key→row 映射，未渲染（其他页/其他分页）的选中行同样执行；
  成功项移出选择、失败项保留 + 行内错误 +「N 项失败」汇总；操作中禁用。
- **必须**：搜索 / 筛选 / 排序变化时清空选择（避免对不可见结果写入）并保持编辑态；
  **翻页不清空**选择（跨页全选/批量依赖它）。切换 tab 仍退出编辑并清空。
- **必须**：非编辑态行为、星标、已掌握对勾、行底色、行展开、单行 checkbox 均不变。
- 验收：三个脚本各 2 次 PASS，覆盖服务端两页全选 / indeterminate / 清除 / 跨页批量 /
  非编辑态无 checkbox；`tsc -b` / `build` / `check:i18n` / `gate-receipt` 绿；1440/375 无溢出。

### 已掌握默认加入时间 + 全词表导出（2026-11-23，P0-16）

## API 契约
### 收藏（M1 ④）

| 端点 | 请求 | 成功 | 失败 |
|---|---|---|---|
| `GET /api/favorites` | — | `200` 数组，最新在前（旧前端契约不变） | `500` 文件损坏 |
| `GET /api/favorites?since=<ms>` | 毫秒时间戳 | `200 {"favorites":[],"deleted":[],"since","serverTime"}` | `422` 参数非整数 |
| `POST /api/favorites` | `{id?, type/kind, text, translation, videoId, time, meta, addedAt?}`；也接受旧的 `en_text/zh_text/start/added_at` | `201 {"status":"ok","created":true,"favorite":{…}}`；重复提交 `200` + `created:false` | `400` 缺 `text` / 非法 `type` / `meta` 非对象 |
| `DELETE /api/favorites/{id}` | — | `200 {"status":"ok","deleted":true,"id"}` | `404` 收藏不存在 |
| `PUT /api/favorites`（兼容） | `{favorites:[…]}` | `200 {"status":"ok","count":N}` | `400` `favorites` 非数组 |

- `favorite` 存储形状保持旧前端字段：`id/type/videoId/start/en_text/zh_text/added_at/highlights/context_en/context_zh`；未知字段原样保留。
- 删除写旁路墓碑 `favorites_tombstones.json`（`{id: deleted_at_ms}`，保留 30 天）。
- 前端使用 `lib/favorites.ts` 的 `fetchFavorites/addFavorite/removeFavorite`；`App.tsx` 先乐观更新本地状态，失败回滚并 toast。`replaceAllFavorites` 只保留为兼容路径，App 不再调用。

### 词表（公开只读，2026-11-17）

| 端点 | 请求 | 成功 | 失败 |
|---|---|---|---|
| `GET /api/vocabulary/lists` | — | `200` 数组：`id/label/count/source/license/notice/approximate/available/version/note`；C2 `available:false` | `503` 数据缺失 |
| `GET /api/vocabulary/lists/{id}?page=1&pageSize=50&q=` | `page≥1`、`pageSize 1–200`、`q` 服务端包含搜索 | `200 {items:[{word,phonetic,translation,cefrLevel}],total,page,pageSize,hasMore}` | `404` 词表不存在/C2；`422` 参数非法；`503` 数据缺失 |
| `GET /api/vocabulary/phrases?page=1&pageSize=50&q=&level=&type=` | `page≥1`、`pageSize 1–200`、`q` 匹配 headword/中文、`level` A2/B1/B2/C1/C1+、`type` phrasal_verb/idiom/collocation | `200 {items:[{id,headword,type,cefr,translation,example,source}],total,page,pageSize,hasMore}` | `400` level/type 非法；`422` 参数非法；`503` 数据缺失 |
| `GET /api/vocabulary/phrases/{id}` | — | `200` 短语详情（列表字段 + `license/notes`） | `404` 短语不存在；`503` 数据缺失 |
| `GET /api/vocabulary/level?words=a,b,c` | ≤100 个词/批 | `200 {word: 'A1'..'C1' \| 'C1+' \| null}`（保留输入大小写） | `422` 空/超量 |
| `GET /api/vocabulary/seen?words=a,b,c` | 需登录；≤100 个词/批 | `200 {word: count}`：`learning_events(type='dict_lookup')` 实时聚合，按小写词形归并、返回 0 而不是缺省 | `403` 游客；`422` 空/超量 |

- C2 未建模：`available:false`，请求 `/lists/cefr-c2` 返回 `404`；前端不请求。
- 词表数据来自仓库只读 JSON（`content/wordlist/`、`content/wordlists/`），无数据库迁移、无 LLM 调用。

## 边界与非目标
- C2 词表尚未建模：不拿 GRE 或频表冒充 C2，也不展示空表当数据。
- 单词本只列生词；句子收藏仍保存在后端（按条 API），当前没有独立列表 UI，也不混入单词本。
- 不内置复习/间隔重复（导出到 Anki 承担复习；应用内复习属 specs/013）。
- 导出是一次性文件下载，不做云同步。
- 仍用每用户 JSON 文件存收藏（不建 `favorites` 表、不改 Alembic）。
- 本轮最小版**不做**：收藏释义指针化（只存 word、渲染查词典缓存）、`word_seen` 物化表、内置词表全量补释义、`favorites.json` → `word_states` 迁移——留作完整版（计划 §3.4），需要单独评审。
