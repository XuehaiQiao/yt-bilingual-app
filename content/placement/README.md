## 题目契约

- `id`：题库内唯一。词汇题 `v-001`…`v-030`，伪词延续 `v-031`…`v-034`（接口
  按词汇题混入，id 不暴露真假），阅读题 `r-01`…`r-05`。
- `band`：`A1` / `A2` / `B1` / `B2` / `C1`（本轮不测 C2）。
- `options`：恰好 4 个互不重复的中文选项。
- `answerIndex`：0–3；**伪词不能有**（没有正确项）。
- `example`（词汇题）/ `passage` + `question`（阅读题）：审校与结果页参考，
  作答时不展示例句。
- `evidence`（阅读题）：正确项对应的原文证据句，仅供教研核对。

## 抽题与评分（实现见 `backend/placement.py`）

- 每次会话按 `sessionId` 确定性抽 **24 词汇 + 3 伪词 + 5 阅读 = 32 题**并打乱；
  词汇按难度带分层（A1 5 / A2 5 / B1 5 / B2 5 / C1 4），保证五带齐全。
- 计分按难度带加权（A1=0.5 … C1=2.5），伪词不计分；伪词选任一选项 = 过度
  声称，压低置信度。`chosenIndex=-1`（或 `null`）= 不认识/跳过。
- 结果只给 CEFR 区间 + 置信度 + 强弱项 + 1 条建议；样本 < 100 用户时一律
  `preliminary: true`，不承诺考试分数。

## 审校清单（接手教研请逐条过）

- [ ] 每个词的难度带是否符合中文学习者实际（不是只看词频表）。
- [ ] 4 个选项是否只有一个正确、干扰项是否有迷惑性但无争议。
- [ ] 中文释义是否自然、无错别字、无方言/歧义。
- [ ] 阅读题的正确答案是否**只能**由原文证据推出，干扰项是否明确错误。
- [ ] 伪词是否确认未被主流词典收录（`floritude` / `quibblestone` /
      `glimmerosity` / `vandrelune`）；若误收真实词立即替换。
- [ ] 正确项位置是否仍打散（`v-*`：9/7/7/7；`r-*`：2/0/1/3/2）。
- [ ] 改完题目把 `_meta.version` / `_meta.updated` 升一版，并同步
      `specs/016-placement/spec.md` 的题库规模。
