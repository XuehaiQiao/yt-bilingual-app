## 1. 取代码、确认、构建

```bash
cd /srv/ln/app
git fetch origin --tags
git checkout 36cfdec
git status --porcelain
git rev-parse --short HEAD

export VERSION="v1.1.1"
export RELEASE_SHA="36cfdec"
export IMAGE_TAG="$RELEASE_SHA"
export OLD_IMAGE_REF="$(docker inspect -f '{{.Config.Image}}' linguatrek-app-1 2>/dev/null || true)"
export OLD_IMAGE_TAG="${OLD_IMAGE_REF##*:}"
echo "old image: $OLD_IMAGE_REF (tag $OLD_IMAGE_TAG)"
test -n "$OLD_IMAGE_TAG" || { echo "找不到旧镜像"; exit 1; }

# 改 .env：APP_VERSION=v1.1.1
grep -E '^APP_VERSION=' .env
# 确认 PUBLIC_BASE_URL / SMTP / 预算无回归后再继续

docker compose build --pull
docker compose config | grep -E 'image:'
docker images | grep linguatrek
```

`git status --porcelain` 必须为空；head 必须是 `36cfdec`。

## 2. 备份 + 离机

```bash

  -v /srv/ln/backups:/backups \
  -v /srv/ln/app/scripts:/scripts:ro \
  -e BACKUP_ROOT=/backups -e ENV_FILE=/dev/null \
```

## 4. 算法分级回填（生产数据，无 schema 变更）

先 dry-run：

```bash
docker compose run --rm --no-deps \
  -v /srv/ln/app/scripts:/app/scripts:ro \
  -v /srv/ln/reports:/reports \
  app python /app/scripts/backfill_content_difficulty.py \
    --only serving --dry-run --report /reports/backfill-dry.json
```

要求 `failed=0`。再正式：

```bash
docker compose run --rm --no-deps \
  -v /srv/ln/app/scripts:/app/scripts:ro \
  -v /srv/ln/reports:/reports \
  app python /app/scripts/backfill_content_difficulty.py \
    --only serving --report /reports/backfill-serving.json
```

### curated（可选）

```bash
docker compose run --rm --no-deps app sh -lc 'ls -l /data/curated-subtitles | head'
```

有字幕缓存才跑：

```bash
docker compose run --rm --no-deps \
  -v /srv/ln/app/scripts:/app/scripts:ro \
  -v /srv/ln/reports:/reports \
  -v /srv/ln/data/curated-subtitles:/data/curated-subtitles:ro \
  app python /app/scripts/backfill_content_difficulty.py \
    --only curated --report /reports/backfill-curated.json
```

没有缓存就跳过；这 30 条仍按编辑级 fallback，不假装回填成功。
