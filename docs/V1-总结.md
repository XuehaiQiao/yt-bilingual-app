## 1. 一页结论

**一句话**：V1 是一个已部署、可供少量受邀用户免费使用的 Web 英语学习产品；核心学习闭环、邀请/账号、余额计费、删除导出、备份告警均已落地，并通过一轮生产 QA。它**不是**公开产品、**不是**收费产品，也**不是**已完成全量验收或法务复核的“正式上线”。

| 问题 | 结论 |
|---|---|
| V1 是什么 | 面向中文用户的 Web 英语学习应用：YouTube/本地内容 → 双语字幕 → 查词/听写/复习 → FSRS；G1 邀请制免费内测。 |
| 当前部署 | `https://linguatrekai.online`，版本 `v1.0.0`，部署 commit `41c463b`，迁移 `0025_balance_cost`；`/healthz` 200、`db.ok=true`。[已核实] |
| 现在能做什么 | 受邀用户注册、登录、使用 AI 功能；管理员发码/调余额/处理删除；本机备份与恢复。 |
| 现在不能做什么 | 公开注册、收费/充值、正式发布公告、承诺长视频稳定、承诺 SLA。 |

**V1 不是什么**

- 不是公开注册产品：公开注册关闭，注册必须邀请码。
- 不是收费产品：没有支付、订阅、充值、退款、发票、对账；$2 是赠送 AI 额度，不是商品。
- 不是“全绿”或“零缺陷”：核心路径有 QA，完整矩阵和长视频未验收。
- 不是“完全合规”：法务文本待复核，未成年/邮件/支付等流程未建。
- 不是高可用/可横向扩展：单 VPS、单容器、SQLite 单写、uvicorn 单 worker。
- 不是移动端/PWA 完整产品：Web 优先，移动端 parity 未做。

## 2. 用户与首发 gate

### 2.1 目标用户

- 中文母语的英语学习者；用真实视频/文章而不是平台自制课程。
- 能在浏览器（桌面或手机浏览器）访问；不要求安装 App。
- 首批为已知用户：通过邀请人获得邀请码，能接受内测的不稳定与人工支持。

| 项 | 当前口径 |

## 4. 技术架构与关键数据模型

### 4.1 请求路径

```text
Browser（React 19 + Vite）
   │ HTTPS
Caddy（TLS/HSTS/CSP，www → apex）
   │ 127.0.0.1:8000
FastAPI（uvicorn，1 worker；API + 静态站点）
   ├─ SQLite app.db（WAL）+ /data 文件
   ├─ SSE 字幕管线（YouTube/yt-dlp → 分批翻译 → 流式返回 → 落盘缓存）
   └─ LLM（DeepSeek 默认 / Gemini 2.5 Flash 可选；严格计费）
```

### 4.2 组件与约束

| 层 | 实现 | 约束/说明 |
|---|---|---|
| 前端 | React 19 + Vite + Tailwind；Hash 路由；i18n zh/vi；IndexedDB | 生产由后端同进程托管静态文件；无 Node 运行时。 |
| API | FastAPI + SQLAlchemy + Alembic；HttpOnly/SameSite=Lax 会话 Cookie | 单进程；统一错误码；`/healthz` 只读。 |
| 流式 | SSE；事件 `meta`/`batch`/`stage`/`summary`/`done`；分批落盘 | 长连接；30 分钟未验收。 |
| AI | `backend/llm.py` 适配层 + `MODEL_CATALOG`；DeepSeek 默认，Gemini 2.5 Flash 可选 | 缺价模型 503；所有 AI 入口登录；Qwen/Gemini 3.x 未定价禁用。 |
| 数据 | SQLite WAL + `/data` 文件；Alembic `0025` | 单写者；不能多副本/多 worker。 |
| 部署 | Docker 单容器 + Caddy 反向代理；uvicorn `--workers 1` | 只绑 `127.0.0.1:8000`；无 Basic Auth。 |

### 4.3 关键数据模型

| 域 | 关键表/对象 | 作用与不变量 |
|---|---|---|
| 账号与访问 | `users`、`sessions`、`invite_codes`、`invite_redemptions` | 邀请码限次/限时/可撤销；注册与换码同事务；一人一码。 |
| 账号生命周期 | `account_deletion_requests`、`data_export_jobs` | 7 天冷静期；导出 ZIP 一次性 token；同一用户同一类任务同时只有一个活动任务。 |
| 计费 | `account_ledger`、`credit_holds`、`model_prices`、`ai_usage`、`ai_quota` | 金额为整数 µUSD；账本 append-only；`available = 余额 − active holds`。 |
| 学习 | `learning_events`、`watch_events`、`word_states`、`review_logs`、`attempts`、`skill_evidence`、`weekly_reports` | 事件幂等/去重；FSRS 到期队列；周报为事实型。 |
| 内容 | `articles`/`article_*`、`imported_books`/`imported_book_translations`、`book_chapter_translations`、`content_items`、`content_teaching_analysis`、`content_difficulty`、`generated_courses` | 公版书在仓库只存元数据+中译文，英文正文按源实时抓取；本地 EPUB 在 `imported_books`；翻译/分析按内容+语言+等级缓存。 |
| 运营 | `app_settings`、`admin_audit_log` | 维护模式/公告/审计；公告前台接线见 7.2。 |

**对账口径**：`SUM(account_ledger.delta_micro_usd)` 应等于 `users.balance_micro_usd`；`ai_usage` 每次调用记录 user、模型、token、价格版本与来源。账本是本地计费记录，不是厂商账单。

### 4.4 AI 调用与计费流程

1. 路由层统一调用 `require_ai_user`；游客/匿名 → 403 `login_required`（不用 401，避免前端误判会话过期）。纯缓存/公开只读路径不拦。
2. 解析候选模型；缺价模型 → 503 `model_unpriced`，**不调用 provider**。
3. 检查余额与配额：余额不足 → 402 `insufficient_balance`；功能/预算超限 → 429。
4. 按候选链最高价预占（`credit_holds`），避免并发调用同时看到同一笔余额。
5. 调用模型；成功按 provider usage 结算，写 `ai_usage` + `account_ledger`；失败/超时/取消释放预占，不扣费。
6. 管理员充扣/调整也走账本；`SUM(delta)=balance` 是对账口径，需在运维/审计时核对（未做自动对账任务）。

### 4.5 邀请、导出与删除

- **邀请**：管理员生成邀请码（限次/限时）→ 用户提交邀请码 + 邮箱/密码/用户名 → 服务端校验注册开关与邀请码 → 事务创建用户、核销邀请码、写 $2 赠送流水。撤销邀请码不影响已注册用户；封禁/踢会话另走账号管理。
- **导出**：用户请求 → 后台任务生成 ZIP（JSON + 用户文件）→ 一次性下载 token（只存 hash）→ 24h 过期；限流与 200MB 上限。
- **删除**：用户提交密码/用户名/确认词 → 进入 7 天冷静期，立即停止 AI 调用与学习数据写入、踢掉会话 → 可取消 → 到期由管理员/安全脚本硬删除。备份中的 PII/口令哈希可能保留至备份保留期（文案口径最长 30 天），隐私文案需与此一致。

### 4.6 本地数据边界

- 本地视频：视频文件本身不上传；浏览器保存 FileSystemFileHandle、封面、进度、字幕文本到 IndexedDB；字幕文本送后端 AI 做翻译/分析。
- 本地剧集：SRT 与媒体文件在用户设备；后端只处理字幕文本。
- 持久句柄依赖 Chromium 的 `showOpenFilePicker`（安全上下文）；其他浏览器降级为一次性选择，不记忆文件。

## 7. 已知限制与风险

### 7.1 R1–R3（G1 可带风险，但阻塞 G2/G3/正式发布）

| ID | 风险 | 当前事实 | 影响 | 缓解 | 计划复核 |
|---|---|---|---|---|---|
| **R1** | 数据单点：离机备份未配 | 本机 `/srv/ln/backups` 有 tar.gz；有一次手工下载校验；无对象存储/第二台机器的自动副本 | VPS 磁盘/机房故障可能丢数据 | T-1 手工下载 + SHA256；首批告知风险；尽快配 rclone/S3/B2 + 生命周期 | 2026-11-28 |
| **R2** | 验证缺口：30 分钟长 SSE、完整 UI 矩阵、管理员后台边缘未最终 QA | 19 秒视频通过；长视频只做短流 | 长视频可能断流；后台/矩阵可能有未发现缺陷 | 首批 3–5 人、先短视频、API 发码兜底、长视频断流即停发码 | 后台 UI 2026-11-24；长 SSE/矩阵 2026-11-25 |

> 风险接受人默认是发布负责人；T-1 签字时写明真实姓名。任何一项在复核日期前恶化，重新做 Go/No-Go。

### 7.2 其他非阻塞限制

- **单点架构**：单 VPS、单容器、SQLite 单写、uvicorn 单 worker；进程内限流/缓存。不要 `scale`、不要加第二个 worker。
- **账号生命周期不完整**：没有邮箱验证、自助找回/改密、会话吊销 UI；忘记密码只能人工处理。这是 G2 的硬前提。
- **公网可达**：无 Basic Auth；未见 WAF/网络层白名单；注册关闭 + 邀请码 + 登录限流是主要闸门。更强隔离需重新评审。
- **UI 治理存量未清零**：设计 token 扫描是 report-only；不能声称“UI 完全合规”。
- **公告未接前台**：`announcement` 目前主要在管理台/设置侧出现，前台未接线；发公告不要只写后台，必须走邀请渠道。
- **法务页**：隐私/条款已是公开页，但无真实可收信支持渠道；反馈走邀请人/管理员。
- **备份含 PII/口令哈希**：目录 700、文件 600；没有离机加密副本；不要把它当作唯一副本。
- **文档漂移**：`docs/上线前任务清单-web.md` 是 11-20 快照（当时收集 1122 项，现为 1243）；`docs/部署执行手册-linguatrekai.online.md` 仍包含 Basic Auth 的摘除/回滚章节，易与当前状态混淆。以 `docs/上线步骤-linguatrekai.online.md` 和当前提交为准。
- **发布标签未推送**：`v1.0.0` 是本地 annotated tag（指向 `41c463b`），截至 2026-11-21 未 push 远端；远端重建按 commit 部署，不要依赖该 tag。
- **法务链接**：只能用 `/#/privacy`、`/#/terms` hash 路径；裸路径返回 SPA 首页，用户看不到条款。
- **能力画像边界**：词汇 Rasch/EAP 为主；阅读证据不足，听说写未测；不是 CEFR 官方认证。
