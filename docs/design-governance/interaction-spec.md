### 0.2 术语

| 术语 | 含义 |
|---|---|
| **路由帧（frame）** | 地址栏 hash 对应的一个页面状态：一级 tab 或子视图。返回 = 弹出一帧。 |
| **覆盖层（overlay）** | 不改变路由、浮在当前帧之上的 UI：词卡、对话框、频道列表、估价遮罩、理解题。 |
| **来源（origin）** | 用户打开当前帧前所在的帧；决定返回落点与 `state.tab`。 |
| **父级（parent）** | 屏幕分类上的上级：列表→详情、tab→子视图。与「来源」不同，深链没有来源时用父级兜底。 |
| **乐观更新** | 先改本地 UI，再等接口；失败回滚。收藏/取消收藏采用此模型。 |
| **首屏加载** | 该区块第一次拿到数据前的加载；此时应使用骨架屏或结构占位，而不是把区域留空。 |
| **刷新失败** | 已有数据后的再次请求失败；保留旧数据 + 行内警告 + 重试，不回退成空态。 |
| **阻断性遮罩** | 盖住全屏、禁止操作、只在「用户已确认的付费处理」等不可并行的动作中使用。 |

### 0.3 不变量（违反即 P0）

1. **失败不得渲染成空态。** 空态只允许出现在「请求成功且结果为空」；`catch` 里不得把列表置空后走空态分支。
2. **页面级导航不得使用全屏阻断遮罩。** 先落 URL 与目标壳（含骨架），再加载数据；失败在页内给错误面板与重试。
3. **破坏性/不可逆操作必须有确认对话框。** 禁止 `window.confirm` / `window.alert`。
4. **模态对话框必须有完整契约**：`role="dialog"`、`aria-modal`、可访问名称、Escape、遮罩点击、焦点陷阱、背景滚动锁、关闭后焦点回填。
5. **收藏/取消必须即时可见。** 不允许「点了没反应」；游客不得出现「看起来已收藏」的假状态。
6. **旧响应不得覆盖新响应。** 同一数据源的请求必须带 generation/AbortController，路由切换或参数变化时取消。
7. **可交互元素必须键盘可达，触屏不依赖 hover。** 触屏命中区不小于 44×44 CSS px（视觉图标可更小，热区补足）。
8. **路由是页面状态的唯一事实源。** 刷新后应恢复的页面状态必须进 URL；不能恢复的必须显式定义兜底，不得静默改写地址后当作成功。
9. **同一语义只有一种反馈层级。** 字段校验内联、操作失败 toast、页面加载失败错误面板、不可并行操作阻断遮罩（见 IX-02）。
10. **文案必须可 i18n。** 交互反馈不得出现硬编码中文/英文/越南语；错误文案遵循 IX-05 的结构。

### 0.4 规则编号与阅读顺序

- `IX-01`–`IX-20`：跨页面通用规则（状态、反馈、弹窗、焦点、导航式加载、表单、门禁）。
- `IX-21`–`IX-28`：具体交互面（点词/收藏/内容切换/危险操作/管理台/登录/分享/搜索）。
- 每条规则固定七栏：**触发 · 行为 · 反馈 · 状态 · 失败/取消 · 返回后状态 · 可访问性**。
- 需要状态机或矩阵的规则，在七栏之后追加图表；图表优先于文字。

## 1. 全局交互规则

<a id="ix-01"></a>
### IX-01 · 异步状态机：加载 / 空 / 错误 / 重试

| 维度 | 规定 |
|---|---|
| **触发** | 任何 `fetch`、流式 SSE、文件读取、写操作完成后需要渲染的区块（一级页卡片、列表、详情、右栏、管理台表格）。 |
| **行为** | 每个异步区块只允许一个状态字段（或一个 discriminated union），取值为 `idle / loading / success / empty / error / refreshing`；渲染分支必须从该状态派生，禁止用「数组长度为 0」同时表示空、失败、未登录。 |
| **反馈** | 首屏 loading 用骨架屏（列表/卡片）或结构化占位；行内刷新用小 spinner；error 用错误面板 + 重试；empty 用空态配方 + 下一步。 |
| **状态** | `idle → loading → success(data) / empty / error`；有数据后请求失败进入 `refreshing → error(stale)`，保留旧数据并显示行内警告，不回退为空。 |
| **失败/取消** | 网络失败、5xx、解析失败、超时都属于 `error`，必须可重试；用户离开/切 tab 时 `abort()`，不得在卸载后 `setState`。 |
| **返回后状态** | 已成功的数据保留在页面状态/缓存中；返回时优先显示缓存，再静默刷新；刷新失败不得清空已显示内容。 |
| **可访问性** | loading 区域 `aria-busy="true"`；错误面板 `role="alert"`；重试按钮有可读名称；空态标题是真实标题层级。 |

**状态转换表**

| 当前 | 事件 | 下一状态 | 附加动作 |
|---|---|---|---|
| `idle` | mount / 进入视口 | `loading` | 记录 requestId；显示骨架 |
| `loading` | 请求成功且有数据 | `success` | 清理错误；更新缓存 |
| `loading` | 请求成功且结果为空 | `empty` | 只在此分支显示空态 |
| `loading` | 请求失败 | `error` | 保存 `errorKind`；显示重试；**不得**置空数据 |
| `success` | 刷新请求开始 | `refreshing` | 保留内容；小 spinner/`aria-busy` |
| `refreshing` | 成功 | `success` | 无闪烁替换 |
| `refreshing` | 失败 | `success(stale)` + 行内警告 | 保留旧数据；重试入口 |
| `error` | 点击重试 | `loading` | 禁用重试按钮；沿用当前筛选/分页 |
| 任意 | 路由切换/组件卸载 | 取消请求 | `AbortController.abort()`；忽略迟到响应 |

**A1 的三处「失败当空态」必须按此修正**

| 位置 | 现状（A1 I-01） | 规范落点 |
|---|---|---|
| `TodayScreen.tsx:95-105` `/api/history` | `catch` 只 `console.error`，`history=[]` → 显示「从第一个视频开始」 | `error` 态：标题「学习记录加载失败」+ 提示 + 「重试」；重试成功后才可能显示空态 |
| `ContentScreen.tsx:121-131` 右栏继续 | 同上 → 显示「还没有学习记录」 | 右栏卡片内错误行 + 重试；不得用空态文案 |
| `ContentScreen.tsx:179-193` `/api/channel-updates` | 失败 → `visibleUpdates=[]` → 「No new uploads yet」 | 订阅卡片内错误行 + 重试；`hasSubscriptions=false` 才是空态 |
| `ContentScreen.tsx:133-163` 本周报告 | 失败时仍走 `content.rail.weekEmpty` | `error` 行 + 重试；「本周还没有数据」只用于成功且为空 |

<a id="ix-02"></a>
### IX-02 · 反馈层级：字段 / 操作 / 区块 / 阻断

| 维度 | 规定 |
|---|---|
| **触发** | 用户提交、校验、保存、删除、加载失败、收藏等需要告知结果的动作。 |
| **行为** | 按影响范围四选一，不得混用（同一失败既弹 toast 又渲染错误面板、或页面级失败只弹 toast，都算违反）。 |
| **反馈** | 见下表。成功优先用「状态本身」表达（星标变实心、行消失、按钮变已完成）；只有无可见状态变化的写操作才补 success toast。 |
| **状态** | 反馈必须与操作的 pending/success/error 状态一致；乐观更新失败必须回滚到精确的前一状态。 |
| **失败/取消** | 用户取消确认框 → 无 toast、无状态变化；操作失败 → 保留输入/上下文，允许原地重试。 |
| **返回后状态** | 成功后的页面状态保留（列表已更新、表单已关闭、滚动不跳）；失败后保持原样并聚焦错误。 |
| **可访问性** | 字段错误 `role="alert"` + `aria-invalid` + `aria-describedby`；toast 区域 `aria-live`；阻断遮罩有可读标题与 `aria-busy`。 |

| 层级 | 使用场景 | 形态 | 禁止 |
|---|---|---|---|
| **字段级** | 表单校验（用户名、密码、URL、金额、必填） | 字段下方内联红字（`text-red-400`），字段边框/焦点环提示；`aria-invalid` | 用 toast 代替字段错误 |
| **操作级** | 收藏失败、删除失败、保存失败、复制失败、支付/处理失败 | `toast.error`（可含「重试」动作时用可操作 toast）；表单提交失败同时保留表单 | 只 `console.error` |
| **区块级** | 页面/卡片/列表首次加载失败 | 该区块内的错误面板：图标 + 一句原因 + 一句下一步 + 重试 | 用空态、用 toast 作为唯一反馈 |
| **阻断级** | 用户已确认的付费处理、必须等待的不可并行任务 | 全屏遮罩 + 进度/说明 + 取消（若可取消） | 导航、tab 切换、普通列表加载使用遮罩 |

> **成功反馈口径**：一级 tab 切换、筛选、展开/折叠、收藏/取消收藏、翻页、开关 → 不弹 success toast；保存设置、导出、复制、删除、调余额/封禁等「无可见结果或高风险」动作 → success toast + 状态更新。

<a id="ix-03"></a>
### IX-03 · 加载态：骨架、行内 spinner、阻断遮罩

| 维度 | 规定 |
|---|---|
| **触发** | 首次加载、刷新、分页、提交、流式生成。 |
| **行为** | 首屏列表/卡片用骨架屏（尺寸与最终内容一致，避免布局跳动）；详情页保持头部稳定、正文骨架；行内刷新用 `Loader2 w-3.5` 级 spinner；按钮提交用按钮内 spinner；流式任务显示真实进度或阶段说明。 |
| **反馈** | 文案用 `common.loading` 仅限短时行内；首屏必须有可感知的结构占位；超过 10 秒的等待补一句「仍在处理 / 可离开此页」的说明（不假装完成）。 |
| **状态** | `loading` 与 `refreshing` 分开：后者不清空旧内容、不改变布局高度。 |
| **失败/取消** | 取消/离开时停止 loading（abort）；失败后 loading 必须结束并进入 error，不得永久转圈。 |
| **返回后状态** | 返回时若已有缓存数据，直接渲染数据 + 静默刷新；不重新展示全屏骨架。 |
| **可访问性** | 骨架 `aria-hidden`，容器 `aria-busy="true"`，提供 `sr-only` 的「加载中」；spinner 不单独作为唯一状态（配文字或 `aria-label`）。 |

| 界面 | 首屏 | 刷新 | 禁止 |
|---|---|---|---|
| 一级页列表/卡片（最近学习、免费资源、书架、频道更新） | 骨架屏 | 行内小 spinner / 保留旧数据 | 居中的大 spinner 导致页面从 0 高度长出 |
| 全屏任务视图（复习、报告、考试、定位） | 页面内加载块/骨架 | 行内状态 | 用白屏或空白代替 |
| 弹窗/词卡 | 弹窗内行内 loading | 同上 | 关闭后仍转圈、loading 溢出到背景 |
| 写操作提交 | 按钮内 spinner + disabled | 不重复提交 | 全屏遮罩（除非 IX-02 阻断级） |
| 流式翻译/处理 | 进度条/阶段文案 + 可离开说明 | 续传提示 | 阻断遮罩盖住已可读内容 |

<a id="ix-04"></a>
### IX-04 · 空态：成功且为空才叫空态

| 维度 | 规定 |
|---|---|
| **触发** | 请求成功、结果为空、筛选无匹配、功能尚未有数据。 |
| **行为** | 使用统一四槽：图标 + 标题 + 一句解释 + 一个下一步动作（可选但推荐）。**尺寸规则（W0 统一）**：页面级 `size=page`（py-16）；独立卡片/区块 `size=card`（py-10）；卡片内部与右栏**内联** `size=inline`（py-3，紧凑行），不套用页面级空态。禁止 py-24/20/12/8。 |
| **反馈** | 区分三类：① **真空**（还没有数据）→ 给创建/开始动作；② **筛选空**（有数据但条件不匹配）→ 给「清除筛选」；③ **不可用**（未登录/无权限）→ 给登录/返回，不叫空态。 |
| **状态** | 空态不是错误态、不是加载态、不是「未登录」；分支必须来自成功结果。 |
| **失败/取消** | 请求失败不得进入空态；筛选清除后回到有数据态。 |
| **返回后状态** | 返回列表时保留筛选/页码；若筛选导致空，仍显示筛选条件与清除入口。 |
| **可访问性** | 空态标题是真实标题（`h2`/`h3`）；动作按钮可键盘达；图标 `aria-hidden`。 |

**允许的例外**：可放置区（导入书书架）可用虚线边框表达「可以往这里放」；普通空态不得使用虚线边框。句子精背的纯文字空态升级为四槽，不允许只有一行字。

<a id="ix-05"></a>
### IX-05 · 错误与重试：错误面板的结构

| 维度 | 规定 |
|---|---|
| **触发** | 区块/页面首次加载失败、刷新失败、写操作失败、流式失败。 |
| **行为** | 错误面板固定三行：**发生了什么**（用户语言，不暴露堆栈/状态码原文）+ **可以怎么做**（重试/登录/返回）+ **一个主操作按钮**。重试复用原请求与原参数；重试期间按钮 spinner 且不可重复点击。 |
| **反馈** | 错误种类决定动作：网络/5xx → 重试；401/403 → 登录/返回；404 → 返回或换一条；429 → 等待提示 + 重试（禁用时可显示倒计时）；校验 → 字段级。 |
| **状态** | `error` 保存 `errorKind`、`lastGood`（可选）；重试失败仍留在 `error`，不清空用户输入。 |
| **失败/取消** | 用户可以返回/离开，不被困在错误页；错误页必须有第二出口（返回/回到内容）。 |
| **返回后状态** | 返回后保留筛选、输入、滚动位置；再次进入重新请求一次。 |
| **可访问性** | 错误面板 `role="alert"` 或 `aria-live="assertive"`；重试按钮有明确名称；错误文本可被读屏完整读出。 |

**文案模板**（i18n key 由 A4 补，禁止拼接后端 `detail` 作为唯一文案）：

- 网络：`无法连接服务，请检查网络后重试。`（`errors.network`）
- 5xx：`服务暂时不可用，请稍后重试。`
- 401/403：`登录状态已失效，请重新登录。` + 登录按钮
- 404：`这条内容不存在或已被移除。` + 返回
- 解析失败：`数据格式异常，请重试或返回。`

> `describeApiError()` 返回的后端 `detail` 可以作为**附加说明**，但不得作为唯一标题；必须先给用户语言的主文案。

<a id="ix-06"></a>
### IX-06 · 竞态、取消、卸载

| 维度 | 规定 |
|---|---|
| **触发** | 同一数据源的连续请求、路由/参数切换、关闭弹窗、组件卸载、流式连接。 |
| **行为** | 每个请求带 `requestId`（或 `AbortController`）；只有最新请求可以提交状态；旧响应到达时直接丢弃。路由切换/卸载时 `abort()`。 |
| **反馈** | 旧请求被取消不提示用户；新请求进入 loading；若新请求失败，显示新请求的错误，不显示旧的。 |
| **状态** | `loading` 必须能被下一次请求替换；不得出现两个 loading 叠加或先到的错误覆盖后到的成功。 |
| **失败/取消** | 用户主动取消（关闭、返回）→ 不报错、不重试；系统失败 → 按 IX-05。 |
| **返回后状态** | 取消不写入缓存、不改变已保存的进度；再次进入重新请求。 |
| **可访问性** | 取消不产生焦点跳跃；新状态用 `aria-busy` 更新。 |

**必须加保护的高风险点**：词卡定义请求（切词）、阅读器文章切换、免费库打开、`/api/history`、频道更新、管理台搜索/分页、流式处理（旧语言流不得画进新语言 UI）。

<a id="ix-07"></a>
### IX-07 · 写操作：提交、防重复、乐观/悲观

| 维度 | 规定 |
|---|---|
| **触发** | 表单提交、保存设置、删除、收藏、调余额/封禁、导出、复制。 |
| **行为** | 提交状态机：`pristine → submitting → success / error`。submitting 时按钮 disabled + 按钮内 spinner；同一操作不得重复提交；成功后关闭弹窗/刷新相关数据；失败保留表单与用户输入。 |
| **反馈** | 无可见结果的写操作 success toast；有可见状态变化的操作不额外 toast；失败 toast + 表单内错误（表单类）。 |
| **状态** | 乐观更新只用于可逆、低风险操作（收藏/取消收藏）；删除、扣额、封禁必须等后端确认（悲观），期间显示 busy。 |
| **失败/取消** | 失败：回滚乐观状态、保留对话框、显示错误、允许重试；取消：无副作用。 |
| **返回后状态** | 成功后的列表/计数已更新；返回不回到旧值；失败后从原位置继续。 |
| **可访问性** | 提交中 `aria-busy`；错误 `role="alert"`；成功 toast `aria-live="polite"`；焦点停在提交按钮或错误摘要。 |

**乐观/悲观选择表**

| 操作 | 模型 | 失败处理 |
|---|---|---|
| 收藏/取消收藏（星标、词卡、句子包、词本行） | 乐观 | 回滚星标/计数 + `toast.error` |
| 从单词本移除收藏 | 乐观 + 可撤销 toast（5s） | 回滚 + 错误 toast |
| 删除历史/文章/书/导入书 | 悲观（先确认） | 保留条目 + 错误 toast |
| 管理台调余额/封禁 | 悲观（确认对话框内 busy） | 对话框不关闭 + 内联错误 |
| 保存设置/改名 | 悲观 | 保留输入 + 字段/表单错误 |

<a id="ix-08"></a>
### IX-08 · Toast：生命周期、去重、位置、读屏

| 维度 | 规定 |
|---|---|
| **触发** | 操作结果（IX-02 操作级）、全局状态（会话失效、离线恢复）、可撤销动作。 |
| **行为** | 三类型 `error / success / info`；同一 `type + message key` 在 5 秒内去重（更新已有条目的计时，不新增）；最多同时 3 条，超出排队；可手动关闭；hover/focus 暂停计时。 |
| **反馈** | 默认寿命：success 3s、info 5s、error 8s；错误文案超过 120 字或带动作时保持到手动关闭。 |
| **状态** | toast 是全局瞬态，不写入记忆/路由；路由切换不强制清空，但同一消息不重复堆叠。 |
| **失败/取消** | 用户关闭 = 确认已读；不得因关闭 toast 改变业务状态；错误 toast 不是唯一错误反馈（页面级必须另有错误面板）。 |
| **返回后状态** | 返回不重放旧 toast；长时间操作完成后的 toast 可跨页面显示（因为操作可能已离开原页）。 |
| **可访问性** | 容器 `aria-live="polite"`；error 用 `role="alert"`/`aria-live="assertive"`；关闭按钮 `aria-label`；不得只靠颜色区分类型（配图标）。 |

**位置规则**

| 断点 | 位置 | 避让 |
|---|---|---|
| ≥md | 右下角，距视口 24px | 不遮挡右侧主按钮；与底部导航无关 |
| <md | 底栏之上：`bottom = 底栏高 56px + env(safe-area-inset-bottom) + 12px` | 子视图无底栏时用 16px；宽度上限 `calc(100vw - 24px)` |
| 离线标记 | **顶栏下方**（不是底部） | 与 toast 分处上下，永久消除 I-10 的重叠 |

**禁止**：用 toast 做字段校验、页面首次加载失败的唯一样式、确认对话框、或需要用户选择「是/否」的操作。

<a id="ix-09"></a>
### IX-09 · 对话框与确认框：一个 Dialog 契约

| 维度 | 规定 |
|---|---|
| **触发** | 需要用户集中注意或确认的操作：设置、导入、分享、删除、退出未完成流程、调余额/封禁、估价确认。 |
| **行为** | 全站只有一套 Dialog 行为契约（视觉由 A2/A4 定）：普通模态 `role="dialog"`，**阻断型**（不可中断处理/强制确认）`role="alertdialog"` + `aria-busy`；`aria-modal="true"`、`aria-labelledby`（必填）、可选 `aria-describedby`；打开时把背景设为 `inert` 并锁 `body` 滚动；焦点移入第一个输入/关闭按钮（破坏性确认聚焦「取消」）；Tab 在对话框内循环；`Escape` 关闭（忙碌/不可取消/alertdialog 时禁用并说明）；点击遮罩关闭（破坏性确认可禁用）；关闭后焦点回到触发元素，触发元素不存在则回到当前页标题。`fullscreen` 变体只用于登录门禁/首次引导（无模糊遮罩/圆角，内容区唯一滚动）。`loading`/`error` 只改 body 状态，不关闭壳；`error` 顶部 ErrorPanel 可重试。 |
| **反馈** | 打开/关闭有动效（尊重 reduced-motion）；提交失败在对话框内显示错误，不关闭；成功关闭并给 toast（若无可见结果）。 |
| **状态** | `closed → open → busy → closing`；同一时刻只允许一个模态对话框，**禁止嵌套**。二级确认二选一：① 先关闭当前对话框（等退出动画结束）再打开新的 ConfirmDialog；② 同一对话框内切换内容（保留焦点陷阱）。不得在关闭动画中打开另一个。 |
| **失败/取消** | 取消/遮罩/Escape 不产生副作用；若已有输入（dirty），先走 `onBeforeClose` 弹「放弃已填写内容？」确认（IX-15）；确认后才关闭，取消则留在框内、焦点回输入；忙碌中禁止关闭或显示「正在保存」。 |
| **返回后状态** | 关闭后页面滚动位置、筛选、未提交草稿（按 IX-15）保持；焦点回填。 |
| **可访问性** | 可访问名称；焦点陷阱；Escape；关闭按钮 `aria-label`；错误 `role="alert"`；背景 `inert`；阻断型 `alertdialog`；不使用 `window.confirm/alert`。 |

**确认框内容规范**

| 字段 | 要求 | 例 |
|---|---|---|
| 标题 | 一句问句，含对象 | 「删除这条学习记录？」 |
| 正文 | 后果 + 是否可恢复 | 「删除后无法恢复，缓存也会清除。」 |
| 取消 | 动词或「取消」，默认焦点 | 「取消」 |
| 确认 | 动词，不用「确定」；危险操作用红色 | 「删除」 |
| 忙碌 | 确认按钮 spinner + 禁用；失败在框内显示 | — |

**已知需替换的实现**：`TodayScreen.tsx:145`、`ReaderScreen.tsx:644`、`ImportedBookReaderScreen.tsx:365`、`InputScreen.tsx:115`（死代码）的 `window.confirm`；`ChannelVideoList.tsx:68-78` 的弹窗（无 Escape/遮罩/role）；`ModelSelectionModal.tsx:59`、`WordPopover.tsx`（缺 role）。统一到 A4 的 `Dialog` / `ConfirmDialog`。

<a id="ix-10"></a>
### IX-10 · 焦点管理与键盘

| 维度 | 规定 |
|---|---|
| **触发** | 路由切换、打开/关闭覆盖层、提交后、错误出现、Tab 导航、快捷键。 |
| **行为** | 路由切换后把焦点移到新页面的主标题/主区域（`tabIndex={-1}`，无可见焦点环），让读屏播报页面名；打开对话框焦点入框；关闭回触发元素；错误出现聚焦错误摘要或第一个错误字段；Tab 顺序与视觉顺序一致。 |
| **反馈** | 焦点必须始终可见（全局 `:focus-visible` 蓝环）；不得用 `outline-none` 且无替代环；焦点不得落到 `aria-hidden`/`inert` 背景。 |
| **状态** | 同一时刻只有一个焦点；覆盖层关闭后不得把焦点留在已卸载节点；焦点回填目标不存在时回主标题。 |
| **失败/取消** | 取消关闭 → 焦点回触发元素；操作失败 → 焦点留在对话框/字段；路由加载失败 → 焦点移到错误面板。 |
| **返回后状态** | 浏览器返回/页面内返回后，焦点回到上一页主区域（不强制回到原触发卡片，避免滚动跳动）；对话框返回必须回触发元素。 |
| **可访问性** | 所有操作键盘可达；图标按钮有 `aria-label`/`title`；动态状态有 `aria-live`；跳转后有页面标题播报。 |

**键盘映射（全局与各视图）**

| 作用域 | 键 | 行为 | 守卫 |
|---|---|---|---|
| 全局 | `Esc` | 关闭最上层可关闭的覆盖层/对话框（有输入且 dirty 时先确认） | 忙碌/不可取消时不关闭 |
| 全局 | `Tab` / `Shift+Tab` | 正常焦点移动；对话框内循环 | 背景 inert |
| 学习页 | `Space` | 播放/暂停 | 焦点在 input/textarea/contenteditable 时不触发 |
| 学习页 | `←` / `→` | 上一句/下一句 | 同上；有对话框时不触发 |
| 学习页 | `R` / `L` | 重播当前句 / 单句循环 | 同上 |
| 理解题 | `1`–`4` / `Enter` / `Esc` | 选项 / 提交或继续 / 退出 | 覆盖层拥有键盘，学习页快捷键暂停 |
| 复习 | `Space` / `1`–`4` | 揭晓 / 评分 | 对话框打开时不触发 |
| 定位 | `1`–`4` / `Enter` / `Esc` | 选项 / 下一题 / 退出（确认） | 提交中禁用 |
| 分栏拖拽 | `←`/`→`/`Home`/`End` | 调整宽度 2% / 最小 / 最大 | 焦点在分隔条时 |
| 对话框 | `Enter` | 非破坏性默认动作 | 破坏性确认不把 Enter 绑定为「删除」；焦点默认在取消 |

### IX-11 · 触屏与 hover

| 维度 | 规定 |
|---|---|
| **触发** | 触摸、笔、粗指针设备；hover 出现的次要操作。 |
| **行为** | 任何 hover 才出现的操作，必须在 `@media (pointer: coarse)` 下常显或提供长按/更多菜单替代；删除、收藏、播放等关键操作不得只在 hover 层。拖动类交互（分栏）必须有按钮/键盘等价。 |
| **反馈** | 触屏按压用 `active:` 背景/缩放（按设计语言），不依赖 hover 颜色；点击目标 ≥44×44。 |
| **状态** | `hover` 只影响视觉提示，不承载业务状态；触屏设备不进入 hover 状态。 |
| **失败/取消** | 触摸误触可取消（例如对话外点击关闭）；不可逆操作必须确认。 |
| **返回后状态** | 触屏返回不依赖 hover 恢复；操作后的状态（收藏/展开）必须保持。 |
| **可访问性** | 键盘/读屏可达；`aria-pressed`/`aria-expanded` 与视觉一致；不以颜色为唯一状态信号。 |

**必须整改的 hover-only 点**：`TranscriptBlock.tsx:200` 的收藏星（现有 `pointer: coarse` 兜底只覆盖这一处）、`App.tsx:2647` 的删除按钮、`ChannelVideoList.tsx:109` 的播放遮罩。规则：粗指针下一律常显；或在移动端用「更多」菜单承载。

<a id="ix-12"></a>
### IX-12 · 导航式内容加载：先路由，后数据

| 维度 | 规定 |
|---|---|
| **触发** | 从任何入口打开学习页/阅读器/书/课程/句子包等内容。 |
| **行为** | 顺序固定为：**校验/确认 → 写入目标 URL（push）→ 渲染目标壳与骨架 → 加载数据 → 成功渲染 / 失败错误面板**。禁止「先 fetch 成功再改路由」或「先全屏遮罩再决定去哪」。 |
| **反馈** | 目标壳立即出现（标题/返回/骨架），让用户知道「已经进入」；估价请求用提交按钮 spinner + 文案，不用全屏遮罩；处理流用学习页内的进度/阶段提示。 |
| **状态** | `switching → loading → ready / error / cacheMiss`；旧内容在切换开始时清空或标记 stale，禁止旧视频/旧文章内容在新路由下短暂可见。 |
| **失败/取消** | 加载失败留在目标路由，错误面板提供「重试 / 返回」；返回键取消加载、回到来源；重试不得自动触发付费处理，处理类操作必须显式按钮 + 费用说明。 |
| **返回后状态** | 返回来源页，保留来源页滚动/筛选/输入；学习页重新进入时按缓存恢复；不自动重译/重跑。 |
| **可访问性** | 切换开始时 `aria-busy` + 可读的「正在打开」；完成后焦点到目标标题；失败焦点到错误面板。 |

**替换现有不一致（A1 I-14）**

| 入口 | 现状 | 规范 |
|---|---|---|
| 内容页免费库视频/文章 | 先 fetch，成功才 `enterLearn`；失败 toast 留在原页 | push 目标路由（`#/content/learn/library/<id>`）→ 壳 + 骨架 → 成功/错误面板 |
| 发现页候选 | 先 `replace` 回内容页，再提交 URL | push 学习路由（`#/content/learn/youtube/<id>`）→ 产线；返回回发现页 |
| 单词本收藏项 | 先关单词本再跳，返回落到「我的」 | push 目标内容（不关闭单词本）→ 返回回单词本（见 IX-23/N-18） |
| 今日/内容粘贴框 | 估价失败直接开始处理、无确认 | 估价失败显示「无法估价，仍要开始？」确认；确认后 push 路由再处理 |

<a id="ix-13"></a>
### IX-13 · URL 状态与瞬态状态边界

| 维度 | 规定 |
|---|---|
| **触发** | 任何会改变页面内容的状态：tab、子视图、文章/书 id、slug、筛选、展开的详情。 |
| **行为** | 必须进 URL：当前 tab、子视图 kind、内容 id/slug、定位视图（`?view=profile`）、内容区锚点（`#/content/library`）、来源 tab（URL 第一段）。不进 URL：词卡、对话框、toast、hover、播放秒数、滚动位置、理解题覆盖层、频道面板。 |
| **反馈** | 地址栏必须与实际界面一致；别名重写必须一次完成并保留可用性；非法路由回落时给一次提示（见 NM-07）。 |
| **状态** | URL 是唯一页面事实源；组件内部状态只能表示「同一路由内的展示细节」，且刷新后要么可恢复、要么明确接受丢失。 |
| **失败/取消** | 写入 URL 失败（非法参数）→ 回落 + 提示；打开覆盖层不写 URL；关闭覆盖层不改 URL。 |
| **返回后状态** | 浏览器后退/前进必须与界面一致；同一路由的 replace（切册、视图）不产生历史条目。 |
| **可访问性** | 路由变化后页面标题/主区域更新，读屏可感知；地址变化不导致焦点丢失。 |

**归属判断口诀**：能被分享/刷新后还应存在 → URL；只在当前操作瞬间有意义 → 组件状态；一次会话内应恢复但不值得分享 → `sessionStorage`（并注明键与清理时机）。

<a id="ix-14"></a>
### IX-14 · 返回后的状态恢复

| 维度 | 规定 |
|---|---|
| **触发** | 从子视图返回、从详情返回列表、tab 切回、浏览器后退。 |
| **行为** | 一级 tab 记录各自滚动位置，切回恢复；列表→详情→返回恢复列表滚动与筛选；阅读器恢复当前文章与阅读进度；学习页恢复播放位置/翻译模式/字幕滚动；单词本恢复 tab/筛选/页码；发现页恢复上次查询与结果；考试恢复草稿；课程恢复当前步骤。 |
| **反馈** | 恢复应是静默的，不闪白、不重新播放动画、不把用户带回顶部；「点当前 tab」是唯一「回顶」语义。 |
| **状态** | 恢复数据存 `sessionStorage`（键含路由/用户维度）或内存 ref；跨设备不承诺；付费处理结果不因返回重跑。 |
| **失败/取消** | 恢复失败（缓存失效/数据被删）→ 回到稳定的父级并提示，不白屏。 |
| **返回后状态** | 见上；若来源页已不可用（内容被删除），落到父级列表。 |
| **可访问性** | 恢复后焦点在主区域，不因滚动恢复而跳到不可见元素；读屏不重复播报整页。 |

<a id="ix-15"></a>
### IX-15 · 未保存变更与草稿

| 维度 | 规定 |
|---|---|
| **触发** | 用户输入后关闭/返回/切换页面；长表单（考试、课程、导入、管理台设置）。 |
| **行为** | 长表单自动保存草稿（本地或后端已有 attempt）；短表单/弹窗表单在关闭前若 dirty，弹「放弃未保存内容？」确认（同一 Dialog 契约）；成功后清理草稿；「重置」类操作必须确认。 |
| **反馈** | 自动保存显示「已保存草稿」轻提示（不打断）；放弃确认说明「离开后未保存内容将丢失」。 |
| **状态** | 草稿状态 `clean / dirty / saving / saved / error`；保存失败不得假装已保存。 |
| **失败/取消** | 取消放弃 → 留在原页、焦点回输入；确认放弃 → 清理草稿；保存失败 → 保留草稿并提示重试。 |
| **返回后状态** | 有草稿的页面重新进入时恢复并标注「已恢复草稿」；用户可明确丢弃。 |
| **可访问性** | 确认框可读；自动保存提示 `aria-live="polite"`；错误输入聚焦。 |

**适用清单**

| 表单/流程 | 草稿策略 | 离开确认 |
|---|---|---|
| 考试答题 | 本地草稿（现有 `writeDraft`），提交后清除 | 进行中退出 → 确认 |
| 课程答题 | 后端 attempt 恢复 | 进行中退出 → 确认（若已有答案） |
| 阅读器导入（URL/正文） | 会话内保留；路由离开即丢 | 有非空输入时返回 → 确认 |
| 导入书弹窗 | 弹窗内保留；关闭时 dirty → 确认 | 是 |
| 管理台设置（维护/公告） | 会话内 draft | 有改动返回 → 确认 |
| 账户改名 | 失焦/取消即丢弃 | 不确认（输入短且可重输） |

<a id="ix-16"></a>
### IX-16 · 表单校验与提交

| 维度 | 规定 |
|---|---|
| **触发** | 输入、失焦、提交、服务端返回字段错误。 |
| **行为** | 提交时校验全部；已 touched 的字段在 blur 后校验；输入变化清除该字段错误；错误显示在字段下方并聚焦第一个错误；单行表单 `Enter` 提交，textarea `Enter` 换行；提交按钮不因「表单无效」而禁用（否则用户看不到原因），只在 submitting 时禁用。 |
| **反馈** | 字段错误内联 `role="alert"`；表单级错误在提交按钮上方；成功关闭/刷新并 toast（如无可见结果）。 |
| **状态** | `pristine / dirty / invalid / submitting / success / error`；服务端错误映射到字段或表单顶层。 |
| **失败/取消** | 失败保留全部输入；取消回到未编辑状态（账户改名）或保留草稿（IX-15）。 |
| **返回后状态** | 成功后离开/关闭；失败留在原位，焦点在第一个错误。 |
| **可访问性** | `label` 关联；`aria-invalid`、`aria-describedby`；错误文本不只靠颜色；密码字段有正确 `autocomplete`。 |

<a id="ix-17"></a>
### IX-17 · 游客门禁：入口提示，不制造 403 白屏

| 维度 | 规定 |
|---|---|
| **触发** | 游客点击需要登录的入口/操作。 |
| **行为** | 所有入口统一调用 `requireAccount()`（或同一 hook）：未登录 → 打开登录浮层，**不改变路由**；用户取消 → 留在原页；登录成功 → 关闭浮层，回到原页；若原操作是「进入某屏」，登录后完成该导航（保存 pendingRoute）；若原操作是收藏等动作，不自动重放，提示用户再点一次。 |
| **反馈** | 登录浮层内说明「登录后即可…」；不弹 403 错误页，不 toast 代替浮层。 |
| **状态** | `guest → login overlay → authenticated`；pendingRoute 只保存一个，登录成功消费一次。 |
| **失败/取消** | 登录失败 → 浮层内字段/表单错误，不关闭；取消 → 清理 pendingRoute。 |
| **返回后状态** | 回到原页面原位置；深链进入受保护屏时，屏内显示登录面板作为兜底（如阅读器），不白屏。 |
| **可访问性** | 浮层焦点陷阱、Escape 关闭（若可取消）、错误 `role=alert`；登录按钮可读。 |

**门禁表**（与 IA §7.4 对齐，入口统一）

| 入口 | 游客 | 行为 |
|---|---|---|
| 今日继续学习 / 本地剧集 / 句子精背 / 免费资源 | 可用 | 不弹窗 |
| 今日/练习复习、本周报告、考试、内容发现、读文章 | 不可用 | 入口 `requireAccount()` → 登录浮层；取消留原页 |
| 定位/能力画像 | 可用（结果提示登录后保存更久） | 不拦 |
| 单词本 | 可用 | 不拦 |
| 管理台 | 不可见 | 手输 URL → toast + 回「我的」，见 NM-12 |

| **失败/取消** | 保存失败回滚选中值 + 错误 toast；取消关闭面板保持原值。 |

### IX-20 · 离线、恢复与刷新

| 维度 | 规定 |
|---|---|
| **触发** | `online/offline` 事件、`visibilitychange`、tab 首次挂载、手动刷新。 |
| **行为** | 离线时显示顶部离线标记（见 IX-08 位置），禁止发起付费/写操作并给可读提示；网络恢复时对只读列表做一次静默刷新；页面重新可见时只刷新 stale 数据；提供手动刷新入口（账户页已有模式）用于列表页。 |
| **反馈** | 离线标记常驻直到恢复；恢复后可 toast.info「网络已恢复」一次（去重）；刷新失败按 IX-05，不把页面清空。 |

| **失败/取消** | 离线中的写操作不排队自动重放（避免重复扣费/重复写），提示用户重试；只读请求可自动重试一次。 |
| **返回后状态** | 恢复后保留页面与筛选；重新进入重新请求。 |
| **可访问性** | 离线标记 `role="status"`/`aria-live="polite"`；恢复提示可读。 |

### IX-22 · 收藏 / 取消收藏

| 维度 | 规定 |
|---|---|
| **触发** | 字幕星标、词卡星标、句子包星标、单词本行取消、收藏来源跳转。 |
| **行为** | 收藏：立即置为已收藏（乐观）+ 计数 +1；取消：立即取消 + 计数 -1；请求在后台；同一 id 的快速连点做合并，以最后一次意图为准。游客点击 → 登录浮层，星标不改变、计数不变。 |
| **反馈** | 星标 `fill` + `aria-pressed` 变化即反馈；不弹 success toast；失败回滚 + `toast.error`；单词本移除提供「撤销」toast（5s）。 |
| **状态** | `idle → pending → saved / error`；每个收藏 id 独立；页面刷新后以服务端/本地存储为准。 |
| **失败/取消** | 失败回滚到精确的前一状态（星标/计数/列表行），保留来源上下文；取消收藏的撤销窗口内再次操作按最新意图。 |
| **返回后状态** | 单词本/来源页的收藏状态一致；从词卡收藏后关闭卡片，计数与列表已更新；来源跳转返回后仍保持。 |
| **可访问性** | 星标按钮 `aria-pressed` + `aria-label`（收藏/取消收藏）+ `title`；触屏常显（IX-11）；状态变化用 `aria-live` 或可读文本提示。 |

**收藏 id 规则**：`vocab-<sourceId>-<word>` / `sentence-<levelId>-<n>` 由单一函数生成；`source_ref` 为空视为 P1 数据缺陷，不得静默显示「来源未知」而不修（A1 I-12）。

### IX-26 · 登录浮层

| 维度 | 规定 |
|---|---|
| **触发** | 游客点击登录/需要登录的入口、会话失效、管理台拒绝。 |
| **行为** | 以覆盖层打开登录/注册，不改变当前路由；若来自门禁，记录 `pendingRoute`（一次）；登录成功关闭浮层并消费 pendingRoute；游客可选择「继续以游客使用」返回原页。 |

|---|---|
| **触发** | 分享卡、导出 Anki/CSV、复制文案、下载 PNG。 |
| **行为** | 打开分享对话框 → 预览 loading → 成功显示预览/操作；导出/复制触发文件下载或剪贴板；失败可重试；本机生成不请求后端（沿用现状）。 |
| **反馈** | 复制成功 toast.success；下载成功可 toast.success（若浏览器无反馈）；生成失败在对话框内错误 + 重试；按钮 busy。 |
| **状态** | `opening / generating / ready / error / exporting`；同一时刻只允许一个分享对话框。 |
| **失败/取消** | 取消关闭、清理临时 canvas/URL；失败保留对话框与重试；剪贴板权限失败给可读提示与备选（长按复制）。 |
| **返回后状态** | 关闭后回到来源页，不改变列表/滚动；导出的文件已下载。 |
| **可访问性** | 对话框契约；预览图 `role="img"` + `aria-label`；下载/复制按钮可读；错误 `role=alert`。 |

### IX-28 · 搜索 / 筛选（P2）

| 维度 | 规定 |

## 3. 端到端状态机（实现对照）

### 3.1 内容打开（导航式）

```
[来源页]
  │ 点击内容（按钮 disabled，防重复）
  ▼
[写入目标 URL（push）] ──► [目标壳 + 骨架]
                              │ load()
                    ┌─────────┴─────────┐
                    ▼                   ▼
                 [ready]            [error]
                    │                   │
                    │            重试 ──┘（保留路由）
                    │            返回 ──► [来源页]
                    ▼
             [播放/阅读/学习]
```

**规则**：任何分支都不得回到「来源页 + 全屏遮罩」；失败时 URL 仍指向目标（可刷新重试），除非用户主动返回。

### 3.2 词卡

```
closed ──点击词──► loading ──成功──► ready ──点击另一词──► loading（旧请求取消）
  ▲                   │                  │
  │                   └──失败──► error ──重试──► loading
  └──── 空白/Esc/X/路由变化/打开对话框 ────┘
```

### 3.3 表单写操作

```
pristine ──输入──► dirty ──submit──► submitting ──成功──► success（关闭/刷新）
   ▲                  │                   │
   │                  │                   └──失败──► error（保留输入，聚焦错误）
   └──取消/重置确认────┘
```

### 3.4 对话框

```
closed ──触发──► open ──submit──► busy ──成功──► closing ──► closed（焦点回填）
                   │                  │
                   │                  └──失败──► open（内联错误）
                   └──Esc/遮罩/取消──► closing（dirty 时先确认）
```
