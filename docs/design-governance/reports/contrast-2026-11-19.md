# 对比度实测报告（2026-11-19，W3 后续）

> **结论：token 文字对 13/13 PASS，0 FAIL。** A 类文字全部 ≥4.5:1；B 类 `fg-muted` 4.12:1 与 C 类 `fg-disabled` 2.57:1 按附录 G 登记为例外；5 个填充色只按非文字记录。

>
> **观测项 2 条（informative，不计 FAIL）：** `fg-muted` 在实际列表行底色 `surface-2/30` 上为 **3.87:1**，hover 态 `surface-2/60` 为 **3.56:1**，低于附录 G 的 4.12 登记值。该用法来自既有共享 `ListRow` 的 meta 行，不是本轮新增；本轮**不改业务 UI**，建议按 P2 跟进（meta 改用 `fg-secondary`，或在附录 G 明确 raised-surface 例外）。
>
> 工具：`scripts/contrast-audit.mjs` v1.0（report-only，不接 CI；默认退出码 0，`--fail` 才在 token FAIL 时返回 1）。

## 5. 使用场景抽查（informative）

> 这些是 token 在实际 alpha 底色上的合成结果，**不属于附录 G「on app」的登记口径**，因此单独列出、不参与 token PASS/FAIL；低于 4.5 的标为 OBSERVE。

| 场景 | 前景 / 合成底色 | 实测 | 结果 |
|---|---|---:|---|
| secondary 按钮文字 | `fg-strong` on `surface-2/60` → `#1B1B1E` | 11.63 | PASS |
| Card 说明文字 | `fg-secondary` on `surface/40` → `#0F0F11` | 7.47 | PASS |
| brand tinted 按钮 / Badge | `brand-300` on `brand/10` → `#091523` | 8.04 | PASS |
| success tinted 按钮 / Badge | `success-fg` on `success/10` → `#0A1B17` | 9.27 | PASS |
| warning tinted 按钮 / Badge | `warning-fg` on `warning/10` → `#21180B` | 10.50 | PASS |
| destructive 按钮 / Badge | `danger-fg` on `danger/10` → `#200F11` | 6.68 | PASS |
| highlight Badge | `highlight-fg` on `highlight/15` → `#1C152E` | 9.89 | PASS |
| **ListRow meta** | `fg-muted` on `surface-2/30` → `#121214` | **3.87** | **OBSERVE** |
| **ListRow hover meta** | `fg-muted` on `surface-2/60` → `#1B1B1E` | **3.56** | **OBSERVE** |

**观测项说明（P2，不在本轮修复范围）**：`ListRow` 的 `meta` 由共享组件固定使用 `text-micro text-fg-muted`。在 `bg-surface-2/30` 的实际行底色上只有 3.87，hover 时 3.56，低于附录 G 的 B 类登记值 4.12。它属于非关键元信息（时间/计数），不承载操作说明，因此不升级为 P1；但既有登记值只按 `app` 底计算，未覆盖 raised surface，建议后续二选一：

1. 将 `ListRow` meta 改用 `fg-secondary`（7.47 on card / 约 7.0 on row，仍保留层级差）；
2. 在附录 G 明确「B 类 4.12 仅限 app 底；raised surface 的 meta 允许更低」并登记该用法。

本轮交付只做矩阵与实测，不改 `ListRow` / token / 其他业务 UI。
