# 语途布局规范（Layout）v1.0

> 作者：A2 · 设计系统架构师 ｜ 日期：2026-11-19 ｜ 阶段：1（门禁 1）
> 依赖：`tokens.md`（下称 T）、`components.md`（下称 C）、A1 `audit-report.md`（下称 A1）、《信息架构-导航重构》（下称 IA）。
> 范围：页面壳、栅格/容器、页面层级、一级页结构、子视图、移动端、空/加载/错误布局；只设计，不改代码。

## 1. 原则与布局档位

### 1.1 三条原则

1. **一个页面只有一个主操作**，且落在首屏中央区（屏高 25%–55%）；次级操作只能以次级按钮/文字链出现。
2. **一个页面只有一个滚动容器**；不允许「页面滚 + 内部再滚」的纵向嵌套（移动端学习页是唯一必须修的反例，见 §7.3）。
3. **壳负责导航，页面负责内容**：壳的宽度/断点/安全区是全局契约，页面只引用档位 token，不自己发明 `max-md:` 补丁。

### 1.2 布局档位（L-11 的裁决）

| 档位 | 范围 | 壳 | 页面 |
|---|---|---|---|
| `compact`（手机） | `< 768` | 顶栏 48 + 底栏 56+safe | 单栏；页内 PageHeader；无侧栏 |
| `regular`（桌面窄） | `768 – 1023` | 顶栏 64 + 文字 tab；无底栏 | 单栏；页内无 PageHeader（标题在顶栏） |
| `wide`（桌面） | `≥ 1024` | 侧栏 240/72 + 顶栏标题；无 tab | 单栏；内容页 `1024–1279` 顶部 rail 横排，`≥1280` 右栏 |
| `large`（宽桌面） | `≥ 1280` | 同上 | 容器可用满 `max-w-page`；内容页两栏 |

- **结构只在 `md`/`lg`/`xl` 变化**；`sm` 只做字号/间距微调（T §8）。
- 禁止 `max-md:` 局部补丁；移动端用默认值 + `md:` 覆盖。
- 1024–1279 是「半桌面」：侧栏已出现，但内容页**不做**两栏（会挤成 368px 主栏），改用 **rail 置顶横排**（§6.2）。这是对 A1 L-03 的采纳（A1 给的两个方案中的第二个）。

## 2. 页面壳（AppShell）

### 2.1 结构（桌面）

```
┌──────────────┬────────────────────────────────────────────────────────────┐
│ Sidebar      │ TopBar h-16：页面标题 15/600 + 副标 11 + 右侧控件          │
│ 240 / 72     ├────────────────────────────────────────────────────────────┤
│ 品牌 h-16    │ Main（唯一内容滚动区，data-page-scroll）                   │
│ 一级 nav     │  max-w-page 1440 + 页内边距 16/24/32                       │
│ 快捷分组     │                                                            │
│ 底部账户     │                                                            │
└──────────────┴────────────────────────────────────────────────────────────┘
```

### 2.2 结构（手机）

```
┌──────────────────────────────────────────┐
│ TopBar h-12：logo 32 + 当前页名 17 + 语言/头像 │  ← 无 4 tab
├──────────────────────────────────────────┤
│ Main（唯一滚动容器）                       │
│  PageHeader（仅一级页）：24/30 + 14 说明     │
│  页面内容……                               │
├──────────────────────────────────────────┤
│ BottomBar h-14 + env(safe-area-inset-bottom) │
└──────────────────────────────────────────┘
```

### 2.3 壳的硬性尺寸

| 元素 | 值 | 备注 |
|---|---|---|
| 根 | `h-dvh overflow-hidden` | 禁止 `h-screen` + 内联 `100dvh` 双写 |
| 侧栏 | 240（展开）/ 72（折叠） | `≥lg`；折叠状态持久化；折叠时不出现文字 |
| 顶栏 | 48（<md）/ 64（≥md） | 顶栏内部 padding 12/16/24 |
| 子视图头 | 48 | C12 SubHeader；`h-12` |
| 底栏 | 56 + safe | 仅 `<md`；子视图隐藏 |
| 内容滚动区 | `flex-1 min-h-0 overflow-y-auto overscroll-contain` | 每页恰好一个 |
| 内容容器 | `max-w-page` + 16/24/32 | 见 §3 |
| Toast | 高于底栏 `56 + safe + 12` | 见 C8 |

### 2.4 滚动所有权（唯一契约）

- 一级页/面板页：**`main` 内只有一个 `data-page-scroll` 容器**（`overflow-y-auto`）。页面里任何 `overflow-y-auto` 都算违规，例外只有：Dialog/Sheet 内部、词卡内部、代码块（当前不存在）。
- 任务子视图（学习/复习/考试/定位/课程）：`AppShell` 隐藏底栏与（任务型）侧栏；子视图自己拥有一个滚动容器 + SubHeader。
- 面板型子视图（单词本/报告/博客/发现/能力/管理台）：保留壳与顶栏面包屑；内容仍只有一个滚动容器；是否显示顶栏 4 tab 由 `isTask` 决定（IA §6.3 / N-17）。
- 学习页桌面：左右两栏各自滚动（视频列不滚、字幕列滚）；学习页手机：**整页一个滚动容器**（§7.3）。
- 切换一级 tab 不保留嵌套滚动位置；同一 tab 内返回保留（A3 负责），布局保证 `scrollTop` 可恢复。

### 2.5 页面标题的唯一性（V-15）

| 视口 | 一级页标题 | 子视图标题 |
|---|---|---|
| `<md` | PageHeader：`text-page` 24 / `md:text-page-lg` 30 + 14 说明 | SubHeader：17/600，h-12 |
| `md–lg` | TopBar：15/600 + 11 副标（无页内 h1） | SubHeader：17/600 |
| `≥lg` | TopBar：15/600 + 11 面包屑（无页内 h1） | SubHeader：17/600 |

- 同一视口**只能有一个 `<h1>`**。桌面端页内 PageHeader 必须 `lg:hidden`；移动端顶栏不显示当前页标题（或只显示 11 小字，不构成第二标题）。
- 一级页标题颜色统一 `fg-primary`；不再出现 `zinc-50` vs `zinc-100` 两套。
- 今日是唯一允许 `display` 字号的页面：`text-page sm:text-display-sm md:text-display`；其他一级页最大 30。

## 3. 容器、栅格与间距

### 3.1 容器

| 用途 | Token | 值 | 说明 |
|---|---|---|---|
| 四个一级页外层 | `max-w-page` | 1440 | 左右内边距 16/24/32，**四个页面必须一致** |
| 一级页内部 measure | `max-w-admin` | 1152 | 「我的」等设置型内容，左对齐（不居中） |
| 管理台 | `max-w-admin` | 1152 | 表格可横向滚动 |
| 单词本/书架 | `max-w-library` | 1024 | — |
| 课程 | `max-w-course` | 768 | — |
| 阅读/博客 | `max-w-reading` | 720 | 长文行宽；双语并排可用 1024 |
| 任务页 | `max-w-task` | 672 | 复习/报告/理解题/考试/定位/能力 |
| 内容页右栏 | `max-w-rail` | 320 | `≥1280` |
| Dialog | 448 / 576 / 896 | — | C4 |

规则：

- 一级页外层容器与 padding 相同；内部 measure 必须**左对齐**在同一页内边距上，不居中、不缩进（避免 A1 V-16 的「内容区突然收窄、左边缘跳动」）。
- 不允许新页面出现 `max-w-5xl`/`max-w-6xl` 的直接使用；只用上表 token。

### 3.2 栅格

| 场景 | 移动 | `md` | `lg` | `xl` |
|---|---|---|---|---|
| 一级页主体 | 1 列 | 1 列 | 1 列 | 1 列 |
| 三行动卡（今日/练习） | 1 列 | **3 列** | 3 列 | 3 列 |
| 内容页 | 1 列 | 1 列 | 1 列 + rail 横排（顶部） | `minmax(0,1fr) 320px` 两栏 |
| 素材库/免费资源卡 | 1 列 | 2 列 | 3 列 | 3 列 |
| 报告/统计 | 1 列 | 2 列 | 3 列 | 3 列 |
| 设置行 | 1 列 | 1 列 | 1 列 | 1 列（measure 1152） |

- 三行动卡统一 `grid-cols-1 md:grid-cols-3 gap-4`；**不再出现 `md:col-span-2 xl:col-span-1` 的异类卡**（L-06）。
- 卡片间距 16（md）/20（lg）/24（3 列 xl）；区块间距 24/32。
- 不允许 `grid-cols-4` 卡墙；每屏统计数字 ≤2 个/卡（IA P-4）。

### 3.3 页面内边距（V-17）

| 页面 | 左右 | 顶部 | 底部 |
|---|---|---|---|
| 一级页 | `px-4 sm:px-6 lg:px-8` | `pt-5 sm:pt-8` | `pb-safe-nav md:pb-6` |
| 子视图（任务/面板） | `px-4 sm:px-6` | `py-4 sm:py-6` | `pb-6`（+ safe 若底部动作条） |
| 阅读器 | `px-4 sm:px-6 lg:px-8` | `pt-3 sm:pt-6` | `pb-10` |
| 学习页 | 0（左右由面板/字幕给 16/24） | 0 | 0 |

- 底部安全区**只加一次**：一级页滚动容器加 `pb-safe-nav`；子视图不加；底栏自身加 `env()`。禁止两处叠加（会多出 72px 空白）。

## 4. 标题 / 描述 / 动作层级

### 4.1 层级表

| 层级 | Token | 用在哪 |
|---|---|---|
| L0 页面标题 | PageHeader 24/30（移动）；TopBar 15（桌面） | 一级页 |
| L1 子视图标题 | SubHeader 17/600 | 复习/报告/考试/定位/阅读器/博客/单词本/课程/学习页 |
| L2 区块标题 | `text-section` 17/600 + `SectionHeader`（可带说明/动作） | 内容页货架、我的分组 |
| L3 卡片标题 | `text-ui` 14/600 或 `text-section` 17/600（仅主卡） | 卡片/列表 |
| L4 正文 | `text-ui` 14 / `text-body` 16（阅读） | — |
| L5 元信息 | `text-micro` 11 / `text-caption` 13 | 时间、计数、来源 |

- 标题不使用 `font-bold`；不超过 600。
- 描述：一级页移动端 14/400 `fg-secondary`；桌面顶栏 11；子视图不再放大段副标题（下沉到内容区）。
- 动作：每个视口一个 primary；secondary 用 `variant=secondary`；低频/危险用 ghost/destructive；链接用 `brand-300` + 下划线（仅正文内）。

### 4.2 SectionHeader（内容页/我的分组）

```
[标题 17/600 fg-primary]  [可选说明 13 fg-secondary]        [可选动作：文字链 13 brand-300 / secondary sm]
间距：上方 24/32，下方 12/16
```

- 不允许每个 section 都套一张大卡；只有主操作/主面板使用 `rounded-panel` 卡片，其余货架用 SectionHeader + 卡片/横排。
- 同一屏 section 标题字号只有 17；不再出现 17/15/13 三种（L-02）。

### 4.3 首屏优先级

| 页面 | 首屏必须看到（从上到下） | 首屏之后 |
|---|---|---|
| 今日 | 主操作（输入/继续卡）+ 复习/报告两张卡的头 | 定位条（仅无画像）、小说课、最近学习 |
| 内容 | 开始学习面板 + 词汇轴开头 + 「素材库」标题 | 素材库、免费资源、推荐、订阅、页脚 |
| 练习 | 复习主卡完整 + 下一张卡的头 | 理解题/考试/定位、页脚说明 |
| 我的 | 账户头 + 余额卡 + 「学习数据」组标题 | 偏好、关于、退出 |
| 学习页 | 视频 + 当前字幕句（不滚动也能看到） | 后续字幕、语言点 |
| 任务页（复习/考试/定位） | 头部 + 主内容 + 主按钮（无需滚动） | 统计/说明 |

- 主操作落在屏高 25%–55%（IA §6.2）；不得放在底栏之上再叠 FAB。
- 首屏不得出现 4 卡并排的指标墙；今日最多 3 卡。

## 5. 一级页布局

### 5.1 今日 `#/today`（L-04 的裁决）

**顺序（固定，不随数据重排）**：

1. 移动端 PageHeader（日期作为标题的一部分；桌面在顶栏）。
2. **主输入槽（固定位置）**：无历史 = `StartLearning variant=primary`；有历史 = `StartLearning variant=compact`（一行，视觉次级）。**永远在页头、永远只有一处。**
3. 三张行动卡：继续学习 / 今日复习 / 本周报告；`md:grid-cols-3 gap-4`；有历史时「继续学习」为视觉主卡，无历史时它是空态引导。
4. 能力定位引导条：仅无画像时显示，一行，低于三卡。
5. 经典小说课程入口（低频，低于三卡）。
6. 最近学习列表（搜索/筛选/分页）——长列表放页尾。
7. **删除页尾的紧凑输入**（当前 `TodayScreen:240-250`），不保留副本。

规则：

- 「无历史」与「有历史」只改变**输入槽的形态**（hero/compact）与继续卡内容；输入槽位置不变。这样用户不会因为数据变化找不到「再来一个视频」。
- 有历史时：继续卡是 primary；compact 输入不得使用白色主按钮，只允许 `secondary/ghost` 级（提交按钮 32 高，字号 13）。
- 顶部「开始学习」（顶栏快捷）跳到**今日**并聚焦输入（不是内容页），与 IA/ L-04 一致。
- 三卡高度不等时以内容自然高度为准，不强制等高；但桌面 3 列顶部对齐。

### 5.2 内容 `#/content`（L-02/L-03 的裁决）

**结构分两层**：

- **Tier A · 主操作区**（一张 `rounded-panel`）：`StartLearning variant=primary` + 两个次入口（发现/读文章）+ 词汇轴（可在主面板下方，作为独立 section）。
- **Tier B · 货架区**（无外层大卡）：素材库（2 卡）、免费资源、公版书、为你推荐、订阅更新、博客页脚。每个货架用 `SectionHeader` + 内容，标题 17，间距 24/32。

**顺序**：

1. PageHeader（移动）/顶栏标题（桌面）。
2. 主操作面板（粘贴链接 + 开始学习按钮；下方发现/读文章文字链）。
3. 词汇水平轴（一行，说明「只决定高亮」）。
4. `1024–1279`：rail 横排（继续学习 + 本周报告，两卡一行）；`≥1280`：rail 进右栏。
5. 素材库（本地剧集 + 句子精背，`md:grid-cols-2`）。
6. 免费资源（视频/文章 panel tabs + 卡片）。
7. 公版书。
8. 为你推荐（横排，可横向滚动）。
9. 订阅更新（频道 chips + 最新视频）。
10. 博客/RSS 页脚。

**两栏规则**：

- `≥1280`：`grid-cols-[minmax(0,1fr)_320px] gap-8`；右栏依次放「继续学习（最多 3 条）」「本周报告入口」「免费库/书架快捷入口」；右栏 `sticky top-6`（可选，不强制）。
- `1024–1279`：主列单栏；继续/报告改为**顶部横排 2 卡**（`grid-cols-2`），不是整宽两列长列表（避免页面高度翻倍）。
- 1024 以下：不显示 rail；继续学习只在今日（内容页最多一条「接着上次」strip，不重复列表）。
- 首屏预算：375×667 必须看到主操作按钮与「素材库」标题的开头；1440×900 必须看到主操作 + 词汇轴 + 素材库标题。

### 5.3 练习 `#/practice`（L-06 的裁决）

1. PageHeader（移动）/顶栏标题。
2. **复习主卡**：全宽 `rounded-panel`；到期/新卡数字 + 一个 primary「开始复习」；游客显示「登录后开始」按钮（不跳页）。
3. **三张同构卡**：理解题 / 考试练习 / 能力定位；`grid-cols-1 md:grid-cols-3 gap-4`；每张卡结构统一：IconTile 40 + 标题 17 + 说明 13（≤2 行）+ 底部动作（secondary/文字链）。**定位卡不再跨列/换向**。
4. 页脚一行说明（不报分、不预测、不含真题），`text-caption fg-muted`，与内容间距 32。
5. 理解题无内容可做时：卡内说明「去继续学习」，不显示空列表。

### 5.4 我的 `#/profile`（L-05 的裁决）

顺序（3 组 + 危险区，组标题 17）：

1. **账户头**：头像 36 + 用户名（内联改名）+ 邮箱 + 注册日期；游客为登录卡。
2. **余额卡**：余额 / 本月 AI 花费 / 今日学习分钟；最多 3 个数字，卡内不放大标题。
3. **学习数据**：单词本（已收藏 N，>99 显示 99+）、本周报告、能力档案（A2–B2 + 置信度 + 更新时间）。行式 `ListRow`。
4. **偏好**：界面语言、翻译目标语言、默认模型、词汇水平（只读 + 去调整）、安装到桌面。行式。
5. **关于与账户**：版本、官方博客、隐私/协议、管理员控制台（仅 admin）。
6. **退出登录**：组尾，`variant=destructive` 的 ghost 按钮（`text-danger-fg`），与上方内容 24 间距。
7. **删除账号**（若存在）：最后，必须 ConfirmDialog；不得与普通行同权重。

规则：

- 每组之间 `mt-8`（32）+ 组标题；组内行间距 8；不再把账户、设置、法律、退出 8 块平铺成同权重。
- 页面外层 `max-w-page`，内容 measure `max-w-admin` 左对齐。
- 游客：账户头为登录卡；单词本/语言/模型仍可用；报告/能力行显示「登录后查看」而不是空。

### 5.5 单词本 `#/profile/vocabulary`（L-07，面板型子视图）

- SubHeader h-12：返回 + 「单词本」17 + 计数；内容 `max-w-library` + 页内边距。
- 顶部：搜索（C3）+ 导出（secondary sm）+ 隐藏中文开关（Segmented 或 switch）。
- TabStrip（C14）：移动端 2 固定 + 「词表」菜单；桌面完整 tab 条可换行。
- 列表：桌面表格（词/等级/释义/来源/时间/操作），移动卡片；分页 C9。
- 空态：C10 EmptyState（「去内容页存词」）；加载骨架 3 行；错误 ErrorPanel。
- 横向滚动只允许 tab 条与表格容器；页面不横向滚。

## 6. 子视图布局

### 6.1 SubHeader（统一）

- `h-12`，`px-3 sm:px-4`；`bg-app/60 backdrop-blur-xl border-b line-subtle z-chrome`。
- 左：BackButton（h-9, -ml-2, ≥sm 显示「返回」）；中：标题 17/600 truncate；右：≤3 个 44 控件（收藏/单词本/PiP/关闭）。
- 头部**不换行**；工具条（译文开关/等级/季选择）下沉到内容区第二行（L-12）。
- 任务页（复习/考试/定位）：头部只保留「返回 + 标题 + 关闭（若需放弃）」；副标题/历史/进度移到内容区（L-09）。

### 6.2 任务页（复习/报告/理解题/考试/定位/能力）

- 容器 `max-w-task`（672）居中；`px-4 sm:px-6`；`py-4 sm:py-6`。
- 首屏：SubHeader + 主内容 + 主按钮；不得要求滚动才能开始。
- 底部动作（评分/上一题/下一题）：`sticky bottom-0`（含 safe）或内容末尾；不使用 fixed 覆盖内容。
- 统计块：`grid-cols-2 md:grid-cols-4 gap-2`；每个数字 `text-ui/600` + 标签 11 muted；不放大数字墙。
- 报告：数字 → 一句事实/下一步 → 证据列表 → 明日到期；证据行可点回学习页。

### 6.3 学习页移动端：单滚动（L-01，P0）

**必须满足（逐条可测）**：

1. 根壳 `h-dvh overflow-hidden`；学习页 = LearningHeader（h-12，sticky top-0）+ **一个**滚动容器（视频 + 字幕 + 摘要一起滚）。
2. **删除**外层 `max-md:overflow-y-auto` 与字幕列 `max-md:h-[52vh]`；删除 `TranscriptView` 的 `h-full overflow-y-auto` 在移动端的内部滚动；删除 `pb-[45vh]`。
3. 视频区：`w-full aspect-video bg-black`，宽度 100%、高度按比例；**不 sticky**（滚走后把屏幕让给字幕）。桌面保持左右两栏、字幕列独立滚动。
4. 字幕：自然高度，`px-4`，`pb-[calc(1rem+env(safe-area-inset-bottom))]`；行距按设计语言。
5. 自动跟随：只在 `activeBlock` 变化时对**页面滚动容器**做一次 `scrollTo`；目标偏移 = `topbar(48) + 12`，用 `scroll-margin-block` 兜底；用户手动滚动后暂停跟随（沿用现有逻辑）。
6. 手势分区不再需要：没有内层滚动，滑动永远作用于整页；桌面分栏拖拽/键盘快捷键在移动端隐藏。
7. 工具栏：LearningHeader 只放返回/标题/单词本；PiP/字号/译文/听写等放内容区第二行，横向可滚，不换行挤压标题。
8. 底部：无底栏（子视图）、无固定 CTA；`scroll-padding-bottom` 由安全区决定。
9. 桌面：`md:flex-row`，左视频列、右字幕列（各自滚动）；分割线仅 ≥md。

**验收（A5 真机）**：375×667 / 390×844 / 430×932，iOS Safari 地址栏展开/收起；字幕区滑动只滚一个容器；滚到底不出现链式滚动；最后一句完整可见。

### 6.4 阅读器/博客

- 容器 `max-w-reading`（720）单栏；双语并排时可用 `max-w-library`（1024）两栏，每栏 ≥320。
- 段落间距 16；**正文标题**（文章名）可用 24/30 并作为全页唯一 `<h1>`；此时 SubHeader 的屏幕名（如「官方博客」）用 17/600 的 `<p>`，不构成第二个 h1。页内工具条在 SubHeader 下第二行。
- 移动端上下排列；译文隐藏时英文单栏，不保留空列。
- 点词/高亮按 C13。

### 6.5 管理台

- 独立壳（无侧栏/底栏），顶栏 64 + 内容 `max-w-admin`；表格容器 `overflow-x-auto`；分页 C9。
- 移动端：表格横向滚动，不撑破页面；筛选/搜索在表头上方一行。

## 7. 空 / 加载 / 错误布局

### 7.1 页面级三态

| 状态 | 布局 | 组件 |
|---|---|---|
| Loading | 页面标题 + 内容区 skeleton（3 行/3 卡），保留最小高度 240，禁止整页 spinner 空白 | C10 Skeleton |
| Error | 页面标题 + `ErrorPanel`（居中，`max-w-task`），标题「加载失败」+ 一句可读原因 + 重试 | C10 ErrorPanel |
| Empty | 页面标题 + EmptyState（page 尺寸），必须有「下一步」动作 | C10 EmptyState |

### 7.2 区块级三态

- 卡片内部：loading 用 skeleton；error 用卡内 ErrorPanel（`p-4`）；empty 用 `size=card`。
- 行内：错误用 13px `danger-fg` 文案（表单/行内），不整块替换。
- 同一请求失败**只能出现一种**呈现：页面级失败不再叠加 toast；操作失败才用 toast。

### 7.3 空态动作（L-10）

| 页面/区块 | 空态动作 |
|---|---|
| 今日·继续学习 | 「贴一条链接开始」→ 聚焦页头输入 |
| 今日·复习 | 「今天没有到期卡 · 明天约 N 张」+ 去练习 |
| 内容·免费资源 | 等级筛选 chip + 去推荐 |
| 内容·订阅 | 「在设置里订阅频道」（若入口存在） |
| 单词本 | 「去内容页存词」→ 内容页 |
| 博客 | 「RSS 订阅」或回内容页 |
| 发现 | 3 个示例主题（可点即搜） |
| 报告（空周） | 「本周还没有学习记录」+ 去继续学习 |
| 阅读器（游客） | 登录卡（不显示空页面） |

### 7.4 刷新与重试（L-14）

- 首次加载失败：ErrorPanel + 重试；重试按钮内 spinner，成功后替换内容。
- 从后台恢复（`visibilitychange` → visible）或 `online`：静默刷新一次；失败不打断当前内容，只保留已有数据 + 顶部轻提示。
- 不允许「只有 mount 时请求一次、无重试」的一级页；「我的」页刷新按钮模式推广到今日/内容错误态（A3/A4 实现）。

## 8. 移动端规则

### 8.1 单滚动与安全区

- `<md`：底栏固定，页面内容滚动容器加 `pb-safe-nav`（`56 + safe + 16`）；子视图无底栏，不加。
- 根壳 `h-dvh`；禁用 `h-screen` / `min-h-screen` / `52vh` / `100vh`。
- `env()` 只在五处：底栏 padding-bottom、一级页 pb、toast bottom、底部弹层、底部动作条。
- `index.html` 已含 `viewport-fit=cover`；不改 meta 的情况下直接使用 `env()`（iOS Safari 有效）。

### 8.2 键盘

- 输入框在移动端字号 ≥16px（防 iOS 自动缩放）。
- 页面不使用 `position: fixed` 的提交按钮；底部动作条用 `sticky`，键盘弹起时随 `dvh` 收缩。
- 输入聚焦滚动：`scroll-margin-block: 16px`；`scrollIntoView({block:'center'})` 时仍要保证不被底栏遮住（滚动容器有 `scroll-padding-bottom`）。
- 键盘打开时 Toast 可能被遮挡：含输入的错误优先内联（字段下），不依赖 toast。

### 8.3 触屏

- 所有操作 ≥44×44；列表行的删除/收藏在 `pointer: coarse` 下常显。
- 无 hover 才能出现的功能（星标、播放遮罩、删除）必须提供常显或「更多」入口（I-16）。
- 不做未定义手势（下滑关闭、滑动返回）；只保留分栏拖拽（桌面）与横向滚动。

### 8.4 底栏与 Toast

- 底栏 `h-14 + safe`，4 项等分；每项 ≥44×56；当前 tab `brand-400` + `aria-current`。
- Toast `left-4 right-4 bottom-safe-nav`；与底栏至少 12px 间距；离线标记不与 Toast 同区。
- 底栏之上保留 16px 呼吸区；最后一张卡完整可见（A4 验收）。

## 9. 桌面 / 平板

### 9.1 侧栏

- `≥lg` 显示；240/72；`h-full`；品牌区 64；4 个一级 tab + 快捷分组；底部账户。
- 折叠：`aria-expanded`；折叠后图标 18、徽章绝对定位；折叠状态持久化。
- 侧栏不抢内容宽度：内容区 `flex-1 min-w-0`；折叠时内容自然变宽，不做二次布局。

### 9.2 顶栏

- `md–lg`：4 个文字 tab（h-9，`text-caption`/`text-ui`）+ 模型/语言/头像；品牌仅 logo。
- `≥lg`：标题 15/600 + 副标 11 + 右侧控件；不再显示 4 tab（避免与侧栏重复）。
- `≥lg` 右侧：模型 chip（可截断 8ch）、语言、头像；「开始学习」快捷按钮仅 `≥lg` 显示。
- 顶栏高度 64；内容滚动从顶栏下方开始，不遮挡。

### 9.3 容器与阅读

- 1440 容器 + 32 页边距；内容页主列（`≥1280`）约 1000–1050，阅读 measure 720（长文）或 1024（双语）。
- 1024–1279：内容页单栏 + rail 横排；不允许两栏（主列会低于 420）。
- 1280+：两栏；rail 320；sticky 可选。
- 管理台 1152；大屏不把表格拉到 1440 满宽（可读性）。
