# 桌面端布局规范（草案 v0.1）

> 状态：**待负责人批准** ｜ 2026-11-23 ｜ 依据：`docs/reports/desktop-layout-audit-2026-11-23.md`（29 个界面实测）
> 目标：修完所有页面后，**桌面空间被合理使用、视觉语言统一**；不是逐页随手调 `max-w-*`。

## 1. 原则

1. **内容决定宽度，不是屏幕决定宽度**：表格/信息流可宽，正文行宽必须保持可读（65–75ch）。
2. **一种页面原型只对应一个容器**：禁止每页自选 `max-w-2xl/3xl/5xl`。统一由 `PageContainer` 的 variant 决定。
3. **宽屏用分栏，不用拉长行**：≥1280px 时，阅读/报告类加右侧栏（目录/语言点/词汇/说明），正文列不变宽。
4. **视觉一致性优先于单页最优化**：页标题、工具栏、卡间距、栏宽、断点全部走同一套 token/组件。
5. **移动端不动**：<768 保持现状；768–1279 单栏加宽；≥1280 双栏。
6. **不引入新颜色/圆角/阴影**：复用现有 design tokens 与 `components/ui/*`。

## 2. 断点与容器

| Token | 宽度 | 用途 |
|---|---:|---|
| `page.focused` | 42rem（672） | 仅表单/确认/对话/登录卡，**不作页面主容器** |
| `page.reading` | 75rem（1200） | 阅读类总宽（正文列 + 侧栏），正文列 `68ch` |
| `page.standard` | 80rem（1280） | 报告/能力/考试/定位/练习/我的 |
| `page.wide` | 105rem（1680，跟主区域） | 内容/今日/免费库/公版书列表/单词本 |
| `page.marketing` | 75rem（1200） | 首页/博客/定价/资源/法律 |

- 应用壳：≥1024 侧栏 240px；主区域上限 1680px（可保留）。
- 双栏断点：**≥1280（xl）**；`grid-template-columns: minmax(0,1fr) 20rem`，gap 24–32px。
- 侧栏宽度统一 320px（20rem），sticky 顶部偏移与页面 padding 对齐。

## 3. 页面原型

| 原型 | 容器 | 布局 | 适用页面 |
|---|---|---|---|
| **信息流/仪表盘** | `page.wide` | 主列 + 可选右栏（320）；卡片 2–3 列 | 内容、今日、免费资源、公版书列表 |
| **表格/清单** | `page.wide` | 单列全宽；表格自己横向扩展 | 单词本 |
| **报告/评估** | `page.standard` | ≥xl 两栏：左指标/正文，右解释/操作 | 周报、能力档案、考试、定位 |
| **阅读** | `page.reading` | 正文列 `68ch` + 右侧栏（目录/语言点/词汇） | 导入文章、免费库文章、公版书、导入书、句子精背、课程 |
| **设置/账户** | `page.standard` | 单列或两栏表单 | 我的、后台 |
| **营销/法律** | `page.marketing` | 法律页 ≥xl 加 240px 目录栏 | 首页、博客、定价、资源、隐私、条款 |
| **表单/对话** | `page.focused` | 居中单卡 | 登录、确认弹窗、空态 |

## 4. 逐页目标

| 页面 | 现状@1440 | 目标容器 | 目标布局 |
|---|---:|---|---|
| 周报 / 能力 / 考试 / 定位 | 672 | standard | ≥xl 两栏（主 2fr + 侧 1fr），最小 1100 |
| 内容发现 / 阅读列表 | 768 | standard/wide | 列表放宽到 ≥1100；筛选栏可与列表并排 |
| 导入文章 / 免费库文章 / 公版书 / 导入书 / 句子 / 课程 | 768 | reading | 正文 `68ch` + 320 侧栏（语言点/词汇/目录） |
| 单词本 | 1024 | wide | 表格吃满主区域；工具栏与表格同宽 |
| 博客 / 定价 / 资源 / 隐私 / 条款 | 1024 | marketing | 1200；法律页加目录侧栏 |
| 练习 / 我的 / 后台 | 1152 | standard | 1200–1280，卡片网格 2–3 列 |
| 内容 / 今日 / 免费资源 / 公版书列表 | 1200 | wide | 保持，右栏可选 |
| 公开首页 | 1024 | marketing | 1200 |

## 5. 统一性要求（视觉协调）

- **页头**：统一用 `PageHeader`（标题/副标题/返回/主操作位置一致）；不允许每页自写标题排版。
- **工具栏**：搜索/排序/筛选与内容同宽、同高度、同间距。
- **卡片**：同一页内 padding 统一 `p-5 sm:p-6`；圆角/边框/底色用 token；列表项密度一致。
- **间距**：页面 block 间距 24px（`gap-6`）；分栏 gap 24–32；页边距 `px-4 sm:px-6 lg:px-8`。
- **正文排版**：阅读正文 `max-w-[68ch]`、`leading-relaxed`；标题层级与现有 design language 一致。
- **侧栏**：宽度/粘性/标题层级/空态统一；不出现“有的页有侧栏、有的页没有同类信息”的分叉。
- **断点**：只在 xl 加双栏；不在 md/lg 出现第三套布局。
- **禁止**：新增颜色字面量、重复造 Card/Stat 组件、按页面写不同标题尺寸。

## 6. 共享组件（先建后用，禁止逐页复制）

1. `PageContainer`：`variant: 'wide' | 'standard' | 'reading' | 'marketing' | 'focused'` + `withRail?`
2. `PageGrid`：`main` + `rail` 槽，≥xl 双栏，窄屏单栏
3. `SideRail`：统一宽度/粘性/标题/空态
4. `ReadingLayout`：正文列 + 侧栏（目录/语言点/词汇三选一）
5. 保留 `PageHeader`；如需“统计卡”抽象 `StatCard`，先核对现有组件不重复（G2）

## 7. 验收指标（每组改完都跑）

1. **宽度**：1440 下页面内容 ≥ 主区域的 75%（focused 原型除外）；1920 下 ≥ 65%；A 组 ≥1100。
2. **可读性**：阅读正文行宽 65–75ch；不因加宽出现超长行。
3. **一致性**：同原型页面页头/工具栏/卡 padding/侧栏宽度一致（截图并排比对）。
4. **无回归**：`tsc/build/i18n/gate-receipt` 绿；现有 Playwright 验收脚本不改断言通过；375 无横向溢出。
5. **证据**：每页 1440/1920 截图，命名带 `@<sha7>`；对照 `desktop-layout-audit` 的改动前后宽度。

## 9. 非目标

- 不重做视觉语言、不改配色/品牌；不改移动端结构；不引入新依赖。
- 不把正文拉到整屏宽；不为“填满”而填满。
