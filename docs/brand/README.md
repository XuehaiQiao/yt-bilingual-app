# 语途 LinguaTrek · 品牌标志

> 方案名：**语音轨迹 / Speech Trail**  
> 一句话：**一句话，一条路。**

## 1. 概念

标志由两个元素组成：

1. **语音气泡**：语言、内容、表达，对应「语」。
2. **三个下坠的圆点**：学习的轨迹与下一步，对应「途」。

气泡不是封闭的图标，而是从一句话延伸出一段路。  
它不承诺“打卡完成”，只表示：**从这段内容出发，继续往前走。**

## 2. 为什么不是章鱼

项目原有的章鱼是**吉祥物**，有亲和力，但作为主标志在 32px 下细节过多，也不直接表达「语言 + 路径」。

本方案保留章鱼作为可选的插画/吉祥物，不把吉祥物和主标志混在一起。  
主标志负责识别，章鱼负责性格。

## 3. 色彩

| 用途 | 色值 |
|---|---|
| 品牌蓝 | `#0A84FF` |
| 深色底 | `#09090B` |
| 浅色文字 | `#F4F4F5` |
| 浅色底文字 | `#09090B` |

只用品牌蓝 + 中性色，不使用渐变、发光或第二强调色。  
这与产品的设计系统一致：单一交互蓝，深色界面，克制。

## 5. 使用规则

### 最小尺寸

- 主标志：**24px** 高
- 横版组合：**160px** 宽
- 竖版组合：**120px** 宽

### 留白

标志四周至少留出 **0.5 个图标宽度** 的空白，不与其他元素贴边。

### 不要

- 不拉伸、不旋转、不改变圆角比例
- 不给标志加阴影、描边、渐变、发光
- 不把蓝色标志放在低对比度背景上
- 不在图标内部再加文字
- 不用旧章鱼图替代主标志

替换前先在实际页面 1440 / 390 两种宽度检查；不要把本目录的探索稿直接上线。
