## 1. 一页结论

### 1.1 产品定位（一句话）

**语途（LinguaTrek）是一个「能证明你学会了的开放内容学习器」**：用户带着自己真正想看的视频/文章/播客来，我们负责把它变成「可理解输入 + 可调度复习 + 一次真实产出 + 一份事实报告」的闭环。

**不是**「AI 英语学习平台」（那是内容公司 + 社区公司 + 考试公司的活，1 人做不动），**也不是**「视频翻译工具」（用户已明确否定，但那恰好是它唯一护城河的入口）。

**一句话判断**：现有产品最强的地方是「用户自带内容 + 可理解输入」——这不是要抛弃的起点，是唯一护城河；开放式学习的正确形态不是「接入更多内容类型」，而是**同一批开放内容对 A 是 i+1、对 B 是 i+5 的可测量个性化**。

### 1.2 差异化（三条，且只有这三条）

| # | 差异化 | 为什么别人难抄 | 对应现有资产 |
|---|---|---|---|
| 差-1 | **真实内容上的个性化难度**：内容难度指纹 × 用户词状态 → 「这条对你约 3% 的词不认识」 | 需要 per-user 词状态 + 离线词频 + lemma 化，是数据活不是模型活；大厂做通用分级，不做「你这条视频」的分级 | 双语字幕块（`history/*.json` 的 `start/end/en_text`）+ ECDICT |
| 差-2 | **错误可回跳到证据时间点**：答错 → 跳回那句原声再看一遍 | 需要「字幕块身份 ↔ 题目证据」的稳定对齐（§8.1 的四元组），这是本产品数据结构天然有的 | `translate.py` 的 id 对齐 + `TranscriptBlock` |
| 差-3 | **反打卡绑架的旅程**：不排名、不红叉、断更不惩罚、周报只报事实 | 与增长常规相反（留存黑招都在制造焦虑），但这是用户自己的学习理论基线（IDEA-0002） | 无（要新建，但便宜） |

> 不做第四条差异化。**社区、考试、音乐、多端都不是差异化，是成本。**
> 但这三条在 v0.9 里只是「设计」——本轮修订为每一条都配了**可验证的机制与门槛**（差-1 → §4.5 UTR 双口径；差-2 → §8.1 证据四元组 + §9.4 两道闸；差-3 → §4.6 周报口径 + §6.1⑦ 带回片段的两个事件）。**未被验证的机制不算差异化。**

### 1.4 MVP 范围与三个时点

**MVP = 一条主线 + 八项地基 + 一条内容线。**

> **主线（唯一验收对象）**：打开 → 今天做什么 → 看 8 分钟 → 3 道理解题（答错回跳证据） → 复习 8 个到期词 → 周末在站内和邮件里收到 1 段事实。
> **八项地基（M1 交付，Gate-0 一次性验收，共 34 人日）**：① 学习事件日志 ② AI 成本账本 + 配额降级链 ③ 迁移框架 + 离机备份 ④ 收藏按条 API ⑤ `jobs` 任务表 + SSE 重连 ⑥ 可观测性 + CI + staging ⑦ 安全最小集 ⑧ 游客态隔离。
> **口径统一说明**：v0.9 同一件事出现过「四件地基」「六件地基（表里只列 5 行）」「①–⑧ 但称六类」三种说法，**本轮统一为八项**，与 §1.5 / §13.2 / §13.3 逐条对应。
> **一条内容线**：用户自带的 YouTube 链接（已有）+ 人工策展 20 条/周（替代搜索与推荐）。

**三个开发时点 + 1 个外部里程碑（本文所有排期的唯一口径）**：

| 时点 | 是什么 | 累计人日 | 周次 | 说明 |
|---|---|---|---|---|
| **Gate-A（可上线 · 免费邀请制）** | 能注册、能看、能复习、能出题（20 人**免费**邀请制试点；**不收钱**） | **112** | **W15** | M1 + M2 + M3 + 验证实验 E-1/E-2；**收款不在本行**，见下行 |
| **收款里程碑（外部依赖，不计入 Gate 序列）** | 能合法收第一笔钱：主体 + 境内域名/服务器 + ICP 备案 + App 备案 + 支付商户号全部就绪 | **不占人日** | **取决于备案，不在 W15/W20 承诺内** | 四项串行，详见 §16；**外部依赖（不可压缩）**，不能靠加班压缩 |
| **Gate-1（MVP 成立）** | 主线闭环 + 周报可送达 + 四条行为判据过三条 | **150** | **W20** | 含 M4 + M5 + E-3 |
| **对外承诺上限** | 含 15% 显式缓冲 | **172** | **W23** | 缓冲是排期块，不是文字安慰（§13.1） |

> **收款与上线拆开（D-1）**：个人主体、暂无境内服务器与域名时，收款本身不合规；**免费邀请制只取消「收款」这一个前置，不豁免 ICP / App 备案**。备案是**人日之外的外部日历**，只能提前、不能靠加班压缩。
> **W15 不变的条件**：若备案从 **W1 启动且 2 个月内完成**，则 **W15 不变**（W9–W15 仍有 6 周余量）；否则 Gate-A 顺延到备案完成后的下一个可用周。**W20/W23 与人日数字不变**，顺延只移动日历。
> **Gate-1 付费判据随之改为「付费意向」**：W20 前若收款里程碑已达成，用真实付费替换；未达成则用 E-1 意向登记（§13.3 / §15.3）。

**MVP 覆盖核算**：完整 4.5 条（2 / 7 / 9 / 13，12 算半条）+ 部分 3 条（1 / 3 / 8）= **7.5 / 13**。

**MVP 明确的三条硬边界**：
1. **不加第二种内容类型**（文章/播客进 V1）——加第二种就会逼出「内容模型重构 + 三套管线」。
2. **不做任何口语/写作自动评分**——ASR 占单人 AI 成本 38% 且不可缓存，且通用 LLM 会把错读「脑补」成正确（**给自信的错分比不给更伤信任**）。
3. **不做 PWA 安装、不做离线包、不做锁屏播放**——只做「手机上能用」（390px、底部导航、触控 ≥44px、对比度 AA、断点续播）。

### 1.5 首个里程碑 Gate-0（W6）

**不追求功能，追求「不可回填的东西已经落地」**。

| 项 | 验收 |
|---|---|

## 2. 产品愿景与设计原则

### 2.1 愿景（三句话，产品语言）

1. **语言学习是一段旅程**——所以产品必须能回答「我在哪一段、这一段我学会了什么、下一段是什么」，而答案只能是**证据**，不能是等级条。
2. **语言的边界就是思想的边界**——所以内容必须是**有思想密度的真实内容**（观点、论证、叙事），题目必须能考「推断与评价」，否则「思想边界」只是文案。
3. **重拾乐趣**——所以产品要**降低门槛而不是增加负担**（宪法原则 1 的原始精神），并且**永不制造愧疚**（不排名、不红叉、不惩罚断更）。

### 2.2 把三句理念翻译成 8 条可执行原则（评审否决项）

| # | 原则 | 可执行含义（怎么写代码/怎么做评审） | 违反的例子（评审直接打回） |
|---|---|---|---|
| P-1 | **证据优先于刻度** | 任何「进步」展示必须挂一条真实证据（哪条内容、哪一秒、哪道题）；里程碑由证据触发，不由天数触发 | 「连续学习 7 天」徽章、进度条百分比 |
| P-2 | **旅程 = 可复现率** | 旅程感的唯一度量是「上周没听懂、这周听懂了」的自述率；UI 只做三件载体：**带回片段、一句话、今天就到这儿** | 阶段动画、成就页、叙事插画、「你太棒了！」 |
| P-3 | **不预约用户的感受** | 不写「你一定会喜欢」；成就文案只陈述事实（「这周你听懂了 12 分钟 TED」），不加形容词 | 「太厉害了」「继续加油」 |
| P-4 | **不体检报告** | 周报最多 3 个数字 + 1 句事实 + 1 个下一步；不并排 4 张指标卡、不做雷达图、不给综合质量分 | 六维雷达图、「学习质量 82 分」 |
| P-5 | **低焦虑** | 不排名、不红叉、不扣分、断更不归零（按周计「3/4 天」）、错 3 次自动降难度而不是标「差」 | 打卡日历、断签清零、排行榜 |
| P-6 | **纠错只在有准备时间的场景** | 看视频/跟读中**不打断、不纠语法**；写作/听写复盘/复习才给反馈 | 播放中弹纠错弹窗 |
| P-7 | **诚实优于漂亮** | 说/写未测就显示「未测」；置信度低就显示「低」；AI 生成就标 AI；样本不足就显示「数据不足」 | 用 LLM 猜一个 B1 填进剖面页 |
| P-8 | **克制** | 新页面默认无 hero、无渐变发光、无装饰动效；装饰只允许出现三处：首启、里程碑、空状态（承宪法原则 5） | 每个 Tab 一个大标题 + 玻璃卡堆叠 |

### 2.3 三个机制：每个机制都必须有**数据来源**

> 原则只写「必须诚实」是不够的——**诚实需要数据**。这一节是本轮修订的重点：三个机制各自补上了「数据从哪来」。

| 机制 | 实现 | 数据来源（缺这行机制就不成立） | 为什么它能替代「提醒」 |
|---|---|---|---|
| **能力证据集（Evidence Cards）** | 每个里程碑是一条可点开的记录：`{日期, 内容标题, 时间点, 我做到了什么}` | 里程碑门槛写在**规则引擎**里（覆盖率/正确率/时长），数据来自 `learning_events` + `attempts` | 门槛不写在文案里 → 造不出来假的 |
| **归航卡（一次结束一屏）** | 每次学习结束：检索到什么（3 个词）+ 一个亮点 + 下一个目的地；按钮只有两个：「今天就到这儿」「再来 3 分钟」 | 检索到的词来自 `word_sources`；亮点来自本次 `attempts`/`review_logs` | 收工是一等公民；用户不需要「自律」来决定何时停 |
| **带回（Bring-back）** | 周报里有 1 段**可播放的 5 秒原声**：「这句你上周没听懂，这周听懂了」 | **两个事件**：`comprehension_miss`（用户点「没听懂」，或同句回听 ≥3 次自动记，带 `content_hash + block_index + start_ms`）与 `bring_back_confirm`（本周卡片上的「再听一遍 → 我懂了」按钮）。**周报只播「上周 miss 且本周 confirm」的句子；没有样本显示「这周还没有可回放的句子」** | 旅程感由**真实音频 + 用户自己的两个动作**承载，不由进度条承载；也不由模型替用户说「你懂了」 |

### 2.4 明确的反模式清单（写进设计评审，违反即打回）

- 排行榜 / 词力对比 / 好友学习时长
- 连续天数（streak）惩罚、打卡日历、断签归零
- 「学习质量分」等不可解释的综合分（**这个词从产品文案里删除**）
- 首页常驻大 hero、无限自动连播下一集
- 播放中弹纠错、红叉、错误音效
- 用 AI 猜「说/写」水平并显示成数字
- 分享「内容集」（二次分发）、公开 feed、陌生人私信

## 3. 目标用户与核心场景

**只做 3 类用户，且明确年龄下限 18 岁**（避开 K12 学科培训资质与未成年人保护的主要义务面；14–17 岁需监护人同意，V1 再评估）。

| # | 用户 | 一句话画像 | 核心场景（何时何地） | 真实痛点 | 现在的产品为什么留不住他 | MVP 是否服务 |
|---|---|---|---|---|---|---|
| U-1 | **有内容、没方法的自学者**（主力，占比目标 60%） | 28–38 岁，能看懂 70%，字幕开着才敢看；囤了 50 个「想看的视频」 | 工作日 21:30–23:00，桌面 30 分钟；周末手机 15 分钟 | 看完了但「没学到东西」；查过的词下次还忘；不知道自己的水平在哪 | 首页是输入框，看完没有出口；查词 = 一次性、无状态 | **是**（主线全部） |
| U-2 | **通勤碎片时间的复习者**（原目标 25%，**MVP 不服务，V1 才重点服务**） | 30–40 岁职场人，每天地铁 20 分钟，只能单手 | 早 8:00 / 晚 18:30，手机，戴耳机，网络不稳 | 想「背单词」但 App 全是打卡与广告；视频看不完、音频不能锁屏 | 手机上只能「看」，复习不存在；切后台任务被杀 | **否**：MVP 只保证「手机上能打开并学完一课 + 断点续播 + 断线重连提示」；锁屏/后台音频/弱网降级/PWA 全在 V1 |
| U-3 | **有考试压力的学生/职场考证者**（占比 15%，V2 才服务） | 大三大四 / 考研 / 四六级 / 雅思 | 桌面，长时段，需要「我到底几分」 | 想要分数与真题 | 无题库、无考试模式 | **否**：V2 做 CET 题型练习 + 分项诊断，**永不报分** |

> **为什么改 U-2**：v0.9 把 25% 的用户押在「地铁/单手/锁屏/弱网」上，同时 MVP 明确不做 PWA、离线、通知、后台音频，M5 只投 4 天布局。**这不是取舍，是自欺。** 本轮改为：U-2 是 V1 的目标，MVP 只承诺可验证的最小行为（见 §15.2 移动验收）。

**明确不做的用户**：K12 学生（资质与未成年人义务）、教师/机构（B 端销售与合规主体，V2 之后）、纯「想看双语字幕」的过客（可以用，但不为它设计）。

**三类用户的共同底层需求（这才是产品的真命题）**：
1. **我现在在哪？**（定位，可信、不装）
2. **我今天学什么？**（今日，3 项以内、10–15 分钟）
3. **我学到了什么？**（报告，事实、可播放、可解释）

> 这三问不成立，考试、社区、多端都没有意义——只是给一辆没有仪表盘的车装更多按钮。

## 4. 能力模型与评估体系

### 4.1 三层表示（各归其位，禁止混用）

| 层 | 名称 | 谁看得见 | 取值范围 | 用途 | 数据来源 |
|---|---|---|---|---|---|
| L1 | **i（难度旋钮）** | 只有系统 + 用户的一个三选一覆盖按钮 | 沿用 004 的 6 档（4k/6k/8k/12k/16k/20k） | 挑词高亮阈值、内容推荐难度、新词配额 | 定位测输出 + 行为校准 + 手动覆盖 |
| L2 | **能力区间（CEFR）** | 用户可见（唯一「等级」） | `A1–A2 / A2–B1 / B1–B2 / B2–C1 / C1–C2` + 置信度徽标（低/中/高） | 对外表达、内容难度的目标带 | 定位测（阅读与词汇识别 = 真实测量；听力 = 行为弱测，标「初步」；说/写 = **未测**） |
| L3 | **考试对标（band）** | P2 才出现 | 不出现分数 | 只给「分项弱项 + 建议练习」 | 考试题型练习的作答数据 |

**三条禁令**：
1. UI 不出现档名（不出现「Liftoff」「Orbit」）——它们降级为内部参数 i。**理由**：盲测显示太空隐喻让用户以为在玩太空游戏，且 Supernova（恒星爆炸）之后没有第七站，「最高级」其实是「到顶就没了」。
2. UI 不出现小数、不出现「B1.3」。
3. **不许用 LLM 猜一个数填进说/写**——显示「未测」比「AI 猜的 B1」诚实，也省一次成本。

### 4.2 技能维度（内部 6 维，对外 4 列）

| 内部维度 | 对外列 | P0 是否可测 | 测量方式 | 备注 |
|---|---|---|---|---|
| 词汇识别（认得出） | 读 | 是 | 定位测词汇题 + 复习卡（认得型） | 主测量 |
| 词汇产出（用得出） | 写 | 弱测 | 语境填空/听写 | 只作内部证据 |
| 听力理解 | 听 | 弱测 | P0：听写正确率 + 回听次数（行为估计，UI 标「初步」、置信度低）；V1：定位测加 5 题听力（用现有字幕片段，不新增音频成本） | **MVP 不做听力测题**（会超出 12 分钟预算） |
| 阅读理解 | 读 | 是 | 定位测阅读 5 题 | 主测量 |
| 口语 | 说 | 否 | —— | **MVP 显示「未测」**；V2 只做「可懂度/流利度/跟读相似度」，不承诺发音分 |
| 写作 | 写 | 否 | —— | V1 只做 rubric 反馈（≤3 条 + 1 亮点 + 一次重写），不打分 |

### 4.3 主动测试设计（spec-012，M4 交付，M2 先用临时版）

| 项 | 设计 | 理由 |
|---|---|---|
| 时长 | **10–12 分钟** | 手机上 15 分钟 + 朗读 + 写作会打掉转化率，而第一周是留存窗口 |
| 词汇 | **24 题**：6 个词频带（1k/2k/3k/5k/8k/12k+）× 4 题，4 选 1 中文释义 + 1 个「不认识」选项 | 分层自适应是 CAT（计算机自适应测验）的廉价近似：24 题内能定到 ±1 个词频带，算法 1–2 天可跑通 |
| 伪词 | 混入 **10% 伪词**（约 2–3 题） | 校正「都认识」的过度声称 |
| 阅读 | **5 题**：1 篇 250–350 词，难度随词汇带自适应，每题带证据句 | 构念与产品行为一致（「你能理解多难的内容」），才有内容效度 |
| 自适应规则 | 每带 4 题；答对 3/4 升带，答错 2/4 降带；24 题或区间收敛即停 | 可解释、可离线、可复现 |
| 计分 | band → 词汇量区间（±1 band ≈ ±1,500 词）→ CEFR 区间 → 映射回 6 档 i | 对外只给区间 |
| **口径** | 词汇量按 **lemma** 计，UI 写「约」 | word family 与 lemma 差 30–40%，不定口径则 4,000 与 6,000 不可比，所有分级都是假的 |
| 题池 | 首发 **200–240 题（8–10 套平行卷）**；同一用户 6 个月内不重复（选项打乱、分批放卷、异常作答检测）；每季度补 **120–150 题** | 600 题池是 6 个月后的目标，不是首发门槛 |
| **停规则验证** | **M4 前先做 1 人日离线 CAT 模拟**：用 200–240 题池模拟 10 组 × 200 名考生，验证「24 题停规则」的分带误差与完成率 | 没有模拟就宣称「±1 带」是猜的；这是评审要求补的最小实验 |
| 结果页 | CEFR 区间 + 三项强弱 + **1 条具体建议** + 一句「这是定位估计，不是考试分数」 | 诚实；也是降低投诉的唯一办法 |
| **效度门槛（改）** | 对外宣称「准确」的准入：**n ≥ 100**（不是 30–50）且 α ≥ 0.85 且 4 周重测 r ≥ 0.80，**并报 95% 置信区间**；或与外部测量相关 r ≥ 0.70（n ≥ 100）。n = 30–50 只够内部检查，结果一律标注「初步估计、置信度低」 | 自适应测验会收窄能力分布、压低 α；n = 40 时 r 的 95% CI 约 ±0.2。用 50 人样本说「信度 0.85」是不诚实 |
| 听力题 | **MVP 不做**（12 分钟预算已满）；V1 加 5 题 → 14 分钟版本 | 保护首周转化率 |
| 不做 | IRT 参数估计（需 200+ 题池 + 几百考生标定）、LLM 现场出题、四项全能、分数预测 | 成本高、不可复现、误导 |

**M2 的临时版（2 人日，必须先有）**：自报 6 档 + 5 道校准题（各档 1 题）+ 难度预览。目的不是准，是**让「今日」与「复习」有一个 i 可用**，不至于把 M2 堵死。

### 4.4 行为校准（P1，不改变对外等级）

| 项 | 规则 |
|---|---|
| 输入信号 | 查词率、回听率（同句 replay 次数）、完播率、答题正确率、复习保持率、收藏后 7 天内是否进入复习 |
| 更新方式 | 滑动平均（28 天）+ 单次证据上限 **±0.15 个子级**（防抖），按 Elo/Rasch 量级更新 |
| 只调什么 | **只调 3 个旋钮**：推荐难度、高亮阈值、每日新词配额 |
| 永不做什么 | **永不改对外显示的 CEFR 区间**（除每 4 周 15 题微测校准） |
| 已知噪声 | 查词 ≠ 不认识（可能是好奇）；不查 ≠ 认识（可能是放弃）→ 只能当弱先验（权重 0.15） |
| 冷启动 | 新用户**没有行为数据**，所以先测（§1.7 裁决） |

### 4.5 难度口径：只留一个指标 `UTR`

> **把「覆盖率」这个词从所有文档里删掉，只留 UTR（unknown-token rate，未知词率）。**

| 口径 | 定义 | 用途 | 计算位置 |
|---|---|---|---|
| **UTR_static（内容静态难度）** | 未在 1k/2k/5k 词表内的 token 数 ÷ 总 token 数；配 WPM（字幕 `start/end` 算）、平均句长 | 内容分级（对「平均用户」）、考试题难度、策展 20 条的打标 | 离线，0 LLM |
| **UTR_user（个人有效难度）** | 不在该用户 `word_states.state ∈ {known-R, known-P, mastered}` 的 token 数 ÷ 总 token 数 | UI 显示「约 3% 的词你不认识」；i+1 判定 | 服务端，0 LLM |

**目标带（首版，用我们自己的数据校准后定稿）**：阅读 **2–5%**；听力 **1–3%**；单条内容新词 ≤ 40 个。
**「正确率 70–85%」改名为「练习目标正确率」，与 UTR 分栏，绝不许混用**（内容难度 ≠ 练习表现，混用一定会有人拿错）。

**lemma 化（已验证的实现路径，0.5–1 人日）**：
1. 命中 `stardict` 且 `exchange` 含 `0:X` → lemma = X（实测 running→run、went→go、children→child、better→good，共 58,625 条命中）；
2. 否则规则剥离：`-ies→y`、`-es`、`-s`、`-ed`、`-ing`（含双写退化）；
3. 不足部分用 ~250 词的不规则表兜底（`was/were/is/are/been` 等高频词实测 `exchange` 为空）。

> **风险**：不做 lemma 化，`run/running/ran` 会被算成 3 个词，UTR 系统性虚高 15–25%，分级全部失真。这一步不能省。

### 4.6 报告指标（spec-015，版本冻结，不许随便加）

**周报 = 3 个数字 + 1 句事实 + 1 个下一步 + 1 段可播放原声。** 送达 = 站内页 + **邮件**（M5 起，§13.2）。

| 数字 | 定义（必须精确到可实现） | 反作弊（必须写进定义） |
|---|---|---|
| 有效输入分钟 | 播放中 ∧ 页面可见 ∧ 非静音 ∧ 未拖动 的累计秒数 ÷ 60；倍速时单独记「投入分钟」 | tab 隐藏 / 拖动进度 / 静音 / 倍速**分别记字段**，报告用「有效」，仪表盘两栏并排 |
| 输出词数 | 写作/复述/听写/填空实际产出的英文 token 数（去重与总量分开） | **排除粘贴**（记输入事件，不取最终文本长度） |
| 到期复习保持率 | 到期卡中评分为「记得」的占比 | 复习评分必须 1–4 四档，不能只有对/错 |

**辅助三数（放在「词汇」小节，不占周报头条）**：本周接触新词数 / 进入复习的词数 / 达到「掌握」标准的词数。
**「掌握」的操作定义（统一）**：**跨 ≥2 个不同日期、独立提取正确 ≥2 次**。
**30 天延迟测**：保留但降为**季度抽样**（从复习队列自动抽 30 词），**不进周报**（否则用户每周看到「上周学的词 0 个」掌握，最伤留存）。
**带回片段**：只播「上周 `comprehension_miss` 且本周 `bring_back_confirm`」的句子（§2.3）；无样本显示「这周还没有可回放的句子」。
**样本不足**（<30 分钟或 <20 题）：显示「数据不足」，不硬算、不画趋势。
**删除**：「学习质量」这个词与任何综合分。

### 6.1 主旅程（8 步，每步给「机制」而不是「页面」）

|---|---|---|
| 算法 | py-fsrs（开源，采用前复核许可证与版本）；SM-2 兜底 | 有日志才谈调参；MVP 不调参，只积累 `review_logs` |
| 目标保持率 | 0.90 | 行业默认；后续用真实日志拟合 |
| 每日上限 | 新卡 5–10（默认 8）；复习 100（可调 20–200） | 90% 保持率下每天 10 新词的稳态是 80–120 张/天，多数人扛不住 |
| 复习:新卡比 | 3–5 : 1 | 防「新卡冲量、复习崩塌」 |
| 积压保护 | 到期 > 150 张时自动切「只复习不新学」；提供「清空积压」（suspend 低频词，**不是删除**） | 复习债是第一杀手 |
| 失败处理 | 连续 3 次失败 → suspend + 降难度（换识别卡） | 低焦虑原则 |
| 卡面 | 4 型；**识别与产出分开调度** | 认得 ≠ 用得出 |
| 语境句 | 一律用 `word_sources` 的来源句（真实、免费、带语境，键 = §8.1 四元组），**不用 LLM 编例句** | 省钱 + 质量更高 |
| 发音 | 复用现有 `tts.ts`（Web Speech）；**设备差异/离线不可用已知**，不列为验收项 | B14 |

### 6.3 目标与成就（反游戏化）

| 项 | 设计 | 为什么 |
|---|---|---|
| 周目标 | 「本周 3/4 天」（按周计，不按连续天数） | 断一天不归零 |
| 每日目标 | 分钟数（10/15/25 三档），不问「你想学多久」，默认 10 | 降低决策成本 |
| 成就 | **能力里程碑**：第一次不看字幕看完 10 分钟 / 第一次 30 秒复述 / 复习 100 词 / 读懂一篇 C1 | 由证据触发，不可伪造 |
| 不做 | 排行榜、XP、徽章墙、连续天数、打卡日历、裂变返利 | 抬高情感过滤，与 P-5 冲突 |
| 通知 | **MVP 只有 1 类送达：周报邮件**（每周 1 封，可退订，默认开但首次弹窗确认）；复习到期提醒 V1（3 类通知合计 ≤2 条/周、22:00–08:00 静默、连续 2 次未读自动降频） | 通知即承诺：点开必须直达那一秒；做不到就不发。v0.9 写了 3 类通知但 MVP 没有通道，自相矛盾 |

### 6.4 跨端连续性契约（3 同步 + 2 合并规则）

- **同步三件**：播放位置（到秒）、复习队列（到期集合 + 熟练度）、能力画像（区间 + 置信度）。
- **契约**：**今日计划由服务端生成一份**，两端展示同一份（不能各自生成，否则用户在两台设备看到两个「今天」）。
- **合并规则**：播放位置取「较新且较大」（防倒退）；复习状态**只能追加**（append-only `review_logs`），不能覆盖（否则离线下的复习会被线上旧状态抹掉）。
- **断点续播**：播放位置每 5 秒写一次（`progress.position_ms`）；重新打开时回到**同一秒**（误差 ≤2 秒）；切换网络/切后台 5 分钟后回来必须能继续。
- 现状提醒：这三件今天全在 localStorage（B9），**是 M1/M2 的改造项，不是优化项**。

## 7. 系统架构

### 7.1 演进策略与容量口径

**单体内演进，不拆微服务、不换数据库（MVP 期内），只加三样东西**：`ai/` 编排层、DB 内 `jobs` 表、`content_items` 统一模型。

理由：3,273 行后端拆 6 个服务 = 一个人维护必死；单进程 + 队列表 + 文件大对象足够撑到已验证规模；Postgres 会同时废掉部署计划 C14/C15/C17 的已验证步骤，并引入 Redis + 对象存储 + 连接池三件新运维面。

> **容量口径（改，评审要求）**：v0.9 写「足够撑到 10 万用户」没有任何压测依据。本轮改为：**已验证容量 ≤ 1,000 MAU / 单实例**（对应「100 并发 SSE + 事件批量写」的压测标准，见 §13.3 Gate-1）；超过 1,000 MAU 前必须补一次容量评估，**不许在对外材料里说「支持 10 万用户」**。

### 7.4 AI 编排（哪些用 LLM、哪些用规则、哪些永不）

| 能力 | 用什么 | 成本 | 缓存 |
|---|---|---|---|
| 字幕翻译 / 总结 | ✅ 现有 LLM 管线（算法原样保留） | $0.07–0.11 / 90 分钟（估算，输出 token 占 92%） | private（第三方）/ shared（自有·公版） |
| 点词释义 | ✅ ECDICT → LLM 兜底（现有链） | 命中本地 = $0 | 按词 |
| 水平估计 / 内容难度 / i+1 | ✅ **规则 + 离线词频**，❌ 不用 LLM | **$0** | 不需要 |
| 学后习题（3 类客观题） | ✅ LLM 生成 + **按 `(content_hash, prompt_ver)` 缓存** + 机械校验 | ≈$0.004/套（首次），摊薄后≈0 | 受 `derivative_policy` 约束（§9.2） |
| 1 句产出反馈 | ✅ LLM + 固定 rubric + 3 条上限 | ≈$0.001/次（限 1 次/日） | ❌ 不可缓存 |
| 周报数字 | ✅ **SQL 算**，❌ 绝不让模型算 | $0 | — |
| 周报叙述 | ✅ LLM 写一段话（基于 SQL 给的数） | ≈$0.001/周 | ❌ |
| 推荐理由 | ✅ LLM 写一句（规则先选） | 低 | 按 query |
| 口语评分 / 发音 | ⚠️ **MVP 不做**；V2 只做可懂度/流利度，不承诺发音分 | ASR 是最大单项（38%） | ❌ |
| 写作批改 | ✅ V1，rubric + 错误分类 + 回归集 | 中 | ❌ |
| 无字幕视频 ASR 回退 | ❌ **MVP 直接明确拒绝**（`faster-whisper` 未安装、无线程池/限速/记账）；V2 前先实测 2 vCPU 上 90 分钟音频的延迟与成本 | 未计入 MVP | — |

**降级链（每个 AI 功能都必须有）**：
`主模型 → 备用厂商（MODEL_CATALOG 已支持 openai_compatible）→ 小模型 → 缓存旧值 → 规则兜底 → 明确告知用户`
> 范本：`routes_user.py:_dict_model_candidates()`。**不要每个功能自己发明降级。**

**模型地域口径（v1.1）**：大陆上线默认使用**国内可用模型**（DeepSeek 国内站 / 通义千问 / Kimi 等，供应商按 D-17 定），**Gemini 仅作海外（越南/其他）可选**；`backend/llm.py` + `MODEL_CATALOG` 的 `openai_compatible` 适配可直接切换，但**必须重测**：翻译/出题质量（同批 20 条字幕人工 A/B）、结构化输出成功率、延迟、成本、内容安全/拒答率（§16.4）。

**配额与预算（M1，硬闸不是提醒）**：
- 三层限额：每用户每功能日限额 → 每用户日预算 → 全局日预算；
- 超限顺序：降级到便宜模型 → 拒绝新增长任务（保留复习/查词）→ 明确告知（「今天的 AI 额度用完了，明天 0 点恢复；复习不受影响」）；
- 决策依据：`cost_ledger` 当日 SUM，**不是估算**。

### 7.6 可观测性与安全

**3 个会叫醒你的告警（只要 3 个）**：① 全站 5xx > 1%（5 分钟）；② 当日 AI 成本 > 日预算 80%；③ 备份未生成 > 24h。其余进日报。

**日志**：JSON 行 + `request_id` + `user_id`（哈希）+ `feature` + `cost` + `latency`；脱敏（email/token/字幕正文**不落日志**）。

**AI 质量遥测（必须落成一个日报页，不是只有指标名）**：
`schema 校验失败率`、`[未翻译] 标记比例`、`重试率`、`题目丢弃率`、`引文存在率（目标 100%）`、`答案可证率（抽检 ≥90%）`、`SSE 断流率`、`任务取消率`、`前端 JS 错误率`。
> 落地面：`/admin/quality` 一页（只读 SQL 聚合），**其中「答案可证率」跌破 90% 触发 1 个告警**（回滚 prompt）。
> 前端错误上报需在同意中心给一个开关（`frontend_error_report`），默认关闭但首启提示一次。

**安全最小集（M1，5 人日 + 持续）**：
限速（注册/登录/估价/处理，按 IP + 账号 + 设备）、登录失败按账号锁定、注册返回统一文案（防邮箱枚举）、全局 LLM 并发信号量、每用户/全局日预算硬闸、URL 白名单（**锚定** `^(https?://)?(www\.|m\.)?(youtube\.com/watch\?v=|youtu\.be/)[A-Za-z0-9_-]{11}$`，替换现有非锚定 `re.search`）、域名解析黑名单（内网/`169.254.169.254`/`file://`）、抓取超时 + 响应大小上限、`_prefetch_cache` → LRU + 容量上限、后台独立角色 + 2FA + 审计日志、提示注入隔离（内容与指令分离 + 输出 JSON schema 白名单 + 禁工具调用 + 单请求 token 上限）。
> **残余风险（显式接受，写进 `docs/运行手册.md`）**：不做 WAF、不做 bot 指纹、不做 IP 信誉库、不做渗透测试。理由：单人维护；对冲 = 日预算硬闸 + 新账号额度延迟发放 + 注册需邮箱验证。**若上线后 30 天内出现 2 次以上批量薅取，立即升级为专项（估 5–8 人日）。**

## 8. 数据模型概要

### 8.1 核心实体（**21 张表 = MVP 20 张 + P1 的 `entitlements` 1 张**）

| `admin_audit` | actor, action, target, payload, created_at | — | 后台所有动作留痕；**不含用户正文** |
| `entitlements`（**P1**） | user_id, plan, period_start/end, grant_json, consumed_json, refund_at | N-1 users | 权益账本，P1 才建（不计入 MVP 20 张） |

### 8.3 稳定块身份（差-2 与复习语境句的地基）

**问题**：`questions.evidence_block_id` 与 `word_sources.block_id` 若指向 per-user `history/*.json` 的块，同一视频不同用户、共享缓存、重切句后 id 都不稳定，**差-2 会在实现时悄悄失效**。

**解**：块身份统一为四元组 **`(content_hash, block_index, start_ms, quote)`**：
- `content_hash`：字幕全文的规范化哈希（去标点/统一大小写/压缩空白后 sha256 前 16 字节）；
- `block_index`：切块后的序号（切块算法版本记在 `content_items.pipeline_ver`，算法升级 → 新 `content_hash` 分支，不原地改）；
- `start_ms`：块起始毫秒（用于回跳定位，容错 ±300 ms）；
- `quote`：原文片段（用于校验与展示）。
**冻结时点**：M1 schema 定稿；M3 出题只写这个四元组；**禁止任何新表再引用 per-user JSON 的块 id**。

### 9.2 版权三分法 → 改成四分（**衍生作品单列**）

| 来源类 | ① 处理（AI 加工） | ② 展示（服务端渲染给本人） | ③ 公开分发（分享卡/公开页） | ④ 导出（Anki/CSV） | ⑤ 离线包 |
|---|---|---|---|---|---|
| 第三方 YouTube | 条件允许（private） | 是，仅本人 | 否 | 限单词/句子（≤N 条，不含整段字幕） | 否 |
| 公版 / 自有 | 是 | 是 | 是 | 是 | 是 |
| 播客 RSS | 按条款 | 是（署名 + 链接） | 否 | 限单词/句子 | 条件 |
| 用户上传 | 是 | 是，本人 | 需本人授权 | 是 | 是 |

> **一句话**：`cache_policy` 管译文，`derivative_policy` 管**题目/总结等衍生作品**。第三方内容的题目默认 **private（同一用户同一内容只生成一次，不跨用户复用）**；跨用户共享必须等法务书面意见后单独开闸。
> 成本影响：按 private 计，题目成本从「全站一次」变成「人均一次」——≈ $0.004/内容/用户，**可忽略**；而法律风险不可忽略。
> **这两个字段现在就要加**（M1 定 schema，M3 落地）——它决定 `content_items` 结构，事后改就是重写下架。

### 9.3 难度标注（分级，全部离线）

每个 `content_items` 落库时算一次 `difficulty_json`：
`{utr_static, utr_by_band: {1k,2k,5k}, wpm, avg_sentence_len, est_cefr, unknown_density_target, word_count, pipeline_ver}`。
- **WPM** 用字幕 `start/end` 算（听力难度的主指标）；
- 首版**不引入 spaCy**（从句密度等句法特征 P2 再上 `en_core_web_sm`）；
- **CEFR 只做对外标签，不做内部调度**（内部调度用 i 与 UTR）。

### 9.4 AI 生成内容的质检（三道闸 + 两个指标 + 一个出口）

**输入纪律**：只给字幕 blocks（`block_index + start_ms + en_text`），**不给标题、封面、频道名**——标题是幻觉的主要来源。

**题目三类（只做能机械判分的）**：
- A 细节理解：4 选 1 + 证据四元组 + `evidence_quote`
- B 词义猜测：目标词 + 上下文，4 选 1（考语境义，不考词典第一义）
- C 听写/填空：答案唯一，逐词 diff

**三道闸（不花模型钱，这是防幻觉的核心）**：
1. **引文存在闸**：`evidence_quote` 必须是 `(content_hash, block_index)` 对应 `en_text` 的**归一化子串**（去标点、统一大小写、压缩空白）；不匹配直接丢弃。指标名 = **引文存在率，目标 100%**。
2. **答案可证闸**：引文是真句 ≠ 答案正确（模型可以引真句却配错项）。因此另设一道：**规则校验（答案唯一、4 选项互异、长度不过分悬殊、禁用「以上都对/都不对」）+ 双模型交叉复核 + 人工抽检 ≥90%**。指标名 = **答案可证率，目标 ≥90%**。
3. **干扰项合理闸**：抽检项（人工判断干扰项是否似是而非、是否靠常识就能排除）。

> **为什么必须拆成两个指标**：v0.9 写「证据不匹配率目标 0」，这只证明了「引文是原文子串」，**没有证明答案能由引文推出**。拆开后，前者是 100% 的机械断言，后者是可观测的质量率。

**QC 状态机**：`auto_generated → auto_checked → human_approved / rejected / reported`。
**节奏（改）**：每周抽 **50 题**人工双评（v0.9 是 20 题/周，对 1,500 题 = 1.3%/周，覆盖率太低）；若人力只能维持 20 题/周，则**把题库首发压到 600 题以内**，不允许「题目多、抽检少」。
**出口**：每题一个「这题有问题」按钮 + 止血台队列（S17）。

### 9.5 题库生命周期（最容易被当成「一次性」的持续成本）

| 阶段 | 动作 | 量级 |
|---|---|---|
| 首发 | 500 句 × 3 题型 ≈ **1,500 题**（规则生成 + 抽检 10%） | 3 人日 + 30 小时抽检 |
| 首发 | 定位测 **200–240 题**（8–10 套平行卷） | ≈6 人日（0.25 h/题） |
| 上线后 | 每周抽检 **50 题** + 举报处理 | 2–3 小时/周 |
| 每季度 | 补 **120–150 题**（曝光失效 + 内容过期 + 模型升级） | **30–50 人时/季，永久**；**季度日历必须写进负责人日程，owner = 内容 QA** |
| 护栏 | 选项打乱、分批放卷（每次只放 2–3 套）、异常作答检测（<3 秒答完/全对/连点） | 每次上新自动跑 |
| 退役 | 曝光 3 次后正确率异常、证据失效、举报确认 | 同上 |

> 记住：**生成一道题 $0.004，养一道题 0.15–0.3 人时。** 「AI 能生成」这句话掩盖的最大成本在后者。

### 9.6 下架流程（止血 S18）

`后台动作 → content_items.status = takedown` → ① 立即停止新渲染 ② 清 `shared` 缓存（带脚本，可重建）③ 分享卡失效 ④ 若涉及用户数据，通知受影响用户 ⑤ 审计日志留痕。
**响应目标**：版权投诉 24h 内首次答复；涉违法内容 4h 内下线；**申诉/纠正**：内容被误下架时 72h 内复核并答复（E2）。

**免费 vs 付费的切法（关键设计）**：**成本≈0 的功能做得慷慨，成本>0 的功能做计量。**

| 档 | 内容 |
|---|---|
| 免费 | 60 翻译分钟/月；**无限查词**（缓存）；**无限复习/生词本**（成本 ≈0，感知价值高）；每周 3 次 1 句产出反馈；基础周报（含邮件） |
| 付费 | 600–1,200 分钟/月；60–100 次输出反馈；全部周报与导出；离线包（V1）；**口语（V1，且不在免费档）** |
| 计量单位 | **「分钟 + 次数」双计量，不用「功能」计量**；免费与付费**同一单位**（否则退款算不清） |

### 11.2 成本模型（必须是脚本，不是文档里的一张表）

**`scripts/cost_model.py` + `config/assumptions.yaml`**：
- 字段：价目 `{model, in_price, out_price, source_url, checked_at}`、三个画像的典型事件流、非 AI 成本（支付/退款/客服/存储/邮件/商店抽成）、敏感度表；
- 规则：**价格未知的模型按「最贵已知模型」计**（宁可高估）；模型下线要能迁移（缓存键含 `model + prompt_ver`）；**每次重试/换模型/`prompt_ver` 失效都算一次全额成本**（必进回归）；
- **进 CI**：配额或 prompt 改动触发成本回归，输出「每人每月成本」与「毛利百分比」。

**价目口径（v1.1）**：下表按 gemini-2.5-flash 计，是**海外/上限**口径；大陆首发改用国内模型后，价目、缓存命中价与延迟都要按供应商官方价重写 `assumptions.yaml`（D-17 定供应商后 W1–W2 完成）。**在重测前，成本表继续按「未知按最贵已知」当上限用**，Gemini 价目只保留作海外档参考。

**三个画像（估算，落地前用真实用量替换；价目基于 `config.py` 的 gemini-2.5-flash $0.30/$2.50 per 1M，核对日 2026-11-15）**：

**单位经济（重算，v0.9 的 82% 是「未含支付真实费率/未含重试/未含商店」的上限）**：

| 情景 | 收入 | AI（含 15% 重试） | 其他成本 | 毛利 | 毛利率 |
|---|---|---|---|---|---|
| 中画像 · 月付 ¥39 · 直连 Paddle | ¥39 | ¥1.15 | ¥10.18 | ¥27.67 | **≈71%** |
| 中画像 · 年付 ¥299 · 直连 Paddle | ¥24.9/月（折） | ¥1.15 | ¥6.00 | ¥17.75 | **≈71%**（费率更低，但单价更低） |
| 重画像 · 月付 ¥39 | ¥39 | ¥5.75 | ¥13.18 | ¥20.07 | **≈51%** |
| 中画像 · 上架商店 30%（P2 原生） | ¥27.3 | ¥1.15 | ¥4.68 | ¥21.47 | **≈55%** |
| 重画像 · 上架商店 30% | ¥27.3 | ¥5.75 | ¥7.68 | ¥13.87 | **≈36%**（低于 Gate-2 的 60% 门槛） |

**三个必须写进定价文档的结论**：
1. **Paddle 5% + $0.5 对 ¥39 月付等于 14%**（海外/上限口径），是第二大成本（仅次于客服）；**大陆走微信/支付宝商户号后约 0.6%–1%，不再是第二大成本，但年付仍是毛利的必要条件**。
2. **上架商店 30% 抽成下，重用户毛利只有 36%** → 原生端要么涨价（¥69/月），要么只卖年付，否则 Gate-2 永远过不了。
3. AI 成本**在 MVP 不是风险**（¥0.15–5.5/人/月）；风险在 V1 的「口语无限练」（ASR 占 38%、不可缓存、一个刷子一天能烧掉一个月预算）→ 口语 V1 才做、默认不在免费档、按分钟限额、优先自托管 ASR 把方差成本变固定成本。

### 11.3 支付路径与现实约束

| 路径 | 可行性 | 周期（日历，不含工程） | 备注 |
|---|---|---|---|
| **微信 / 支付宝商户号** | **大陆收款主路径**，需主体 | **1–3 周（估算）** | 需主体 + 对公/个体户账户 + ICP 备案；费率约 0.6%–1%（以合同为准）；**D-1 后的收款里程碑**（§16） |
| 国内个人收款 | 否，**不合规** | — | 个人收款码不能作为经营性收款通道；必须主体 + 商户号 |
| 国内主体（个体户/企业） | 有条件 | **1–3 个月不可压缩** | 主体 + ICP 备案 + App 备案 +（生成式 AI）备案/安全评估 + 商户号；**先个体户跑通，再公司升级** |

**D-1 后的路径**：收款 = 主体（个体户/公司）→ 境内域名/服务器 → ICP / App 备案 → 微信/支付宝商户号。**Paddle 只服务海外（越南）**，不再是 MVP 关键路径；MVP 免费邀请制不阻塞 Gate-A，具体周期与责任人见 §16。

**计费系统（P1，≥50 付费用户再做）**：权益账本（plan/period/grant/consumption/rollover/refund clawback）+ webhook 幂等（event id 去重）+ dunning（扣款失败重试 + 通知）+ 升降级按比例折算 + 拒付证据链 + 发票。
> 现在不做的理由：没有真实付费用户前，权益模型的每个字段都会猜错（结转、降级、退款回收）——**先拿使用信号，收款里程碑后再按真实工单建模型**，反而少返工。

### 12.2 安全威胁模型（M1 最小集，来自对现有代码的结构性观察）

| 面 | 现状（结构性观察，非「已出事」） | 最小动作 |
|---|---|---|
| 注册 | 无速率限制 → 脚本批量注册 → 免费额度变免费 API | 注册限速 + 邮箱验证 + 新账号额度延迟发放 |
| 登录 | 进程内 dict + 只按 IP 限流；无按账号锁定 → 撞库不受阻 | 账号级锁定 + 失败退避 |

| 提示注入 | 字幕/文章进 LLM 已是事实 | 内容与指令分离 + 输出 schema 白名单 + 禁工具调用 + 单请求 token 上限 |
| 后台 | 现在是「登录/未登录」二元 | 独立 role + 2FA + 审计日志 |
| 邮件 | 无 SMTP、无 DKIM → 找回邮件进垃圾箱 = 账号无法找回 | ESP + SPF/DKIM/DMARC + 退信处理（S9） |

### 13.1 产能假设与三本账（先说清楚，否则排期都是假的）

## 15. KPI 与验证实验

### 15.1 北极星指标

**WCL（Weekly Closed-Loop Learners，周闭环学习者）= 一周内完成「输入 ≥10 分钟 + 复习 ≥1 次 + 有 ≥1 次输出（题或产出）」的用户数。**

为什么不是 DAU/时长/注册数：观看时长是 YouTube 的指标，不是学习的指标；注册数在邀请制下无意义；DAU 会被「挂着视频」污染。WCL 是唯一直接对应「我们真的让他在学」的数。

### 15.2 关键漏斗与目标值

| 阶段 | 指标 | MVP 目标 | 备注 |
|---|---|---|---|
| ① 落地 → 首次「听懂」 | 60 秒内产生第一次听懂占比 | ≥ 60% | 游客态先听 |
| ② → 注册 | 听完后注册率 | ≥ 35% | 现在 AuthScreen 是硬门槛 |
| ③ → 完成定位 | 注册当日完成定位（或临时定位）占比 | ≥ 70% | 12 分钟太长会掉 |
| ④ → 首次闭环 | 7 天内完成一圈（看→查→复习→周报） | **≥ 40%** | **Gate-1 判据** |
| ⑤ → 复访 | W4 留存 | **≥ 20%** | Gate-1 判据 |
| ⑥ → 付费意向 | 试点 20 人中登记「收款开放后愿付 ¥29」 | **≥ 8 人** | Gate-1 判据；**收款里程碑后用真实付费替换**（D-1） |

### 15.3 上线前 3 个低成本验证实验（**17 人日，已计入总账**）

| # | 实验 | 时点/成本 | 怎么算成功 | 失败怎么办 |
|---|---|---|---|---|

## 16. 中国首发合规与落地清单

> **v1.1 新增**，回答 D-1 落地后的问题：**在写下一行代码之前，哪些事必须由谁在什么时候做完。**
> 所有周期都是**日历估算**（不是人日），标「估算」的必须用真实办理结果替换；**本节不构成法律意见**，W1 必须由律师复核。
> 本节**不改变 §13 的人日与 W20/W23 口径**：合规是人日之外的外部日历，只能提前、不能靠加班压缩。

### 16.1 一句话结论

**免费邀请制解决的是「收款不合规」，不解决「无备案上线」。** 大陆首发的最小合法路径是：**主体（个体户优先）→ 境内域名 + 境内服务器 → ICP 备案 → App 备案（按分发形态）→ 生成式 AI 路径确认（D-17）→ 隐私/ToS/版权/内容审核 → 微信/支付宝商户号（收款里程碑）**。其中**主体与备案必须在 W1 启动**——它们是 W15 之前唯一「不能靠加人解决」的串行依赖。

## 附录 C：术语与口径

| 术语 | 定义（一句话） | 不许怎么写 |
|---|---|---|
| **i** | 内部难度旋钮（6 档），只调高亮阈值/推荐/新词配额 | 不在 UI 显示档名（Liftoff 等） |
| **CEFR 区间** | 对外唯一「等级」，形如 `B1–B2`，带置信度徽标 | 不写 `B1.3`、不写「你相当于雅思 6.5」 |
| **UTR** | unknown-token rate，未知词率；分 static / user 两种口径 | **不再使用「覆盖率」** |
| **掌握** | 跨 ≥2 个不同日期、独立提取正确 ≥2 次 | 不是「收藏过」、不是「看过」 |
| **有效输入分钟** | 播放中 ∧ 页面可见 ∧ 非静音 ∧ 未拖动 的秒数 ÷ 60 | 不是「总时长」 |
| **输出词数** | 实际产出的英文 token（去重/总量分开），排除粘贴 | 不是「文本长度」 |
| **WCL** | 周闭环学习者（北极星指标） | 不是 DAU |
| **复习债** | 到期未复习的卡片积压量 | 不做「断签」叙事 |
| **private / shared（cache_policy）** | 内容**译文**是否允许跨用户复用（默认 private） | 不说「共享能省钱」就把默认改成 shared |
| **derivative_policy** | 内容**衍生作品（题目/总结）**是否允许跨用户复用（第三方默认 private） | 不把它和 cache_policy 合成一个字段 |
| **证据四元组** | `(content_hash, block_index, start_ms, quote)`，块与证据的唯一身份 | 不再用 per-user JSON 的块 id |
| **引文存在率 / 答案可证率** | 前者 = 引文是原文子串的比例（目标 100%）；后者 = 答案能由引文推出的比例（≥90%） | 不要合成一个「证据不匹配率」 |
| **止血台 / 运营台** | 后台两级：4 个急救动作 / 5 个日常页面 | 不做 SPA、不做数据大屏 |
| **假名化** | 保留记录但把 `user_id` 换成不可反推的 `pseudonym_id`，删 salt 即断链 | 不写「删了就是匿名」（仍有准标识符） |
