# v1.1.1 分级回填操作单

> 目标：生产按**算法级**展示，与本地一致；不回填编辑级。
> 前置：备份 `data/app.db`；确认生产 `current=0033`；不要动用户表/学习数据。

## 1. 备份

```bash
cd /srv/ln/app
docker compose run --rm --no-deps \
  -v /srv/ln/backups:/backups \
  -v /srv/ln/app/scripts:/scripts:ro \
  -e BACKUP_ROOT=/backups -e ENV_FILE=/dev/null \
  --entrypoint /bin/bash app /scripts/backup.sh --keep 7
```

## 2. Dry-run（只读）

```bash
cd /srv/ln/app
docker compose run --rm --no-deps \
  -v /srv/ln/app/scripts:/app/scripts:ro \
  app python /app/scripts/backfill_content_difficulty.py \
  --only serving --dry-run --report /tmp/backfill-dry.json
```

看 `computed/failed/skipped`；failed 非 0 先停。

## 3. 回填 serving

```bash
cd /srv/ln/app
docker compose run --rm --no-deps \
  -v /srv/ln/app/scripts:/app/scripts:ro \
  app python /app/scripts/backfill_content_difficulty.py \
  --only serving --report /tmp/backfill-serving.json
```

## 4. Curated（如果生产有字幕缓存）

```bash
ls -l /srv/ln/app/data/curated-subtitles 2>&1
# 有缓存才跑：
docker compose run --rm --no-deps \
  -v /srv/ln/app/scripts:/app/scripts:ro \
  -v /srv/ln/app/data/curated-subtitles:/data/curated-subtitles:ro \
  app python /app/scripts/backfill_content_difficulty.py \
  --only curated --report /tmp/backfill-curated.json
```

没有字幕缓存就跳过，并在审计里标记这 30 条为 fallback。

## 5. 复核

```bash
docker compose run --rm --no-deps \
  -v /srv/ln/app/scripts:/app/scripts:ro \
  app python /app/scripts/content-difficulty-backfill.py \
  --api-base http://127.0.0.1:8000 \
  --out /tmp/difficulty-audit.json
```

期望：

- `remote.computed = 147`（serving+curated 完整时）
- `remote.displayMismatch = 0`
- `outsideAlgorithm = 5`（C2 保留编辑级兜底）

## 6. 抽检

- `free-app-hidden-cost`：本地/线上都应显示 **B1**（算法）
- `eci-stand-verb`：算法 B2 与编辑 A1 不一致，按决策保留算法显示，记录待优化
- 文章/视频列表抽 10 条，确认等级稳定

## 7. 回滚

分级表是缓存数据；回滚用备份 `restore.sh` 或重跑旧版本回填。不要改用户数据表。
