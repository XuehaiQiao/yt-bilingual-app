# v1.1 上线操作单（复制粘贴版）

> 适用：Docker Compose 部署（`/srv/ln/app`，数据卷 `linguatrek-data`）。
> 裸机 systemd 版把 `docker compose ...` 换成对应宿主命令，见
> [v1.1 runbook](../reports/v1.1-launch-migration-2026-11-25.md) §3.1。
> **先把下面 5 行变量改成你的值；其余命令按顺序整段复制。**

## 0. 变量（只改这里）

```bash
export APP=/srv/ln/app
export DOMAIN=linguatrekai.online
export RELEASE_SHA=填release-commit
export BACKUP_ROOT=/srv/ln/backups
export DRILL=/tmp/v11-$(date +%Y%m%d-%H%M%S)
```

## 1. 发布门禁（在开发机/CI，不在生产）

```bash
cd "$APP" && git fetch --tags
git checkout "$RELEASE_SHA"
test "$(git status --porcelain | wc -l | tr -d ' ')" = "0" && echo "OK: clean"
cd "$APP/backend" && venv/bin/python -m pytest tests -q
cd "$APP/frontend" && npx tsc -b && npm run build && npm run check:i18n
cd "$APP" && node scripts/v11-p0-acceptance.mjs && node scripts/admin-feedback-acceptance.mjs
```

全部通过再继续。

## 2. 填生产环境变量（不要提交、不要截图）

编辑 `/srv/ln/app/.env`，确认/追加：

```dotenv
APP_VERSION=v1.1.0
PUBLIC_BASE_URL=https://linguatrekai.online
# SMTP 未配置时找回密码不会真正送达
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_SSL=false
SMTP_STARTTLS=true
SMTP_USER=
SMTP_PASSWORD=
SMTP_FROM=no-reply@linguatrekai.online
SMTP_TIMEOUT_SECONDS=10
```

检查（不打印密码）：

```bash
cd "$APP"
sudo -u ln grep -E '^(APP_VERSION|PUBLIC_BASE_URL|SMTP_HOST|SMTP_FROM)=' .env
# 只判断密码非空，不打印
sudo -u ln grep -q '^SMTP_PASSWORD=.' .env && echo "SMTP_PASSWORD 已填" || echo "❌ SMTP_PASSWORD 为空"
```

## 3. 备份 + 离机副本

```bash
cd "$APP"
sudo -u ln mkdir -p "$BACKUP_ROOT"
docker compose run --rm --no-deps \
  -v "$BACKUP_ROOT":/backups \
  -v "$APP/scripts":/scripts:ro \
  -e BACKUP_ROOT=/backups -e ENV_FILE=/dev/null \
  --entrypoint /bin/bash app /scripts/backup.sh --keep 7

STAMP=$(date +%Y%m%d-%H%M%S)
ARCHIVE=$(ls -1t "$BACKUP_ROOT"/linguatrek-backup-*.tar.gz | head -1)
sig="$BACKUP_ROOT/offsite-$STAMP.sha256"
sha256sum "$ARCHIVE" | tee "$sig"
# 离机（rclone 示例；桶名/远端按你的配置改）
rclone copy "$ARCHIVE" remote:linguatrek-backups/
rclone copy "$sig" remote:linguatrek-backups/
```

没有离机备份，不要继续。

## 4. 停写 + 迁移前基线

```bash
cd "$APP"
docker compose stop app

mkdir -p "$DRILL"
docker compose run --rm --no-deps -v "$DRILL":/out \
  app python scripts/v11_data_snapshot.py \
  --db /data/app.db --users /data/users --out /out/pre.json

docker compose run --rm --no-deps app alembic current
docker compose run --rm --no-deps app alembic heads
# 期望 current 是生产实际版本；heads 唯一 = 0033_v1_1_launch
```

## 5. 升级

```bash
cd "$APP"
docker compose run --rm --no-deps app alembic upgrade head
docker compose run --rm --no-deps app alembic current
# 期望 0033_v1_1_launch
```

## 8. 回滚（只在需要时）

### 8.1 代码回滚（首选，保留 0033）

```bash
cd "$APP"
git checkout <上一个 release-sha>
docker compose build --pull
docker compose up -d
curl -fsS http://127.0.0.1:8000/healthz | python3 -m json.tool
```

### 8.2 数据库降级（会丢 v1.1 新表/验证状态）

```bash
cd "$APP"
docker compose stop app
docker compose run --rm --no-deps app alembic downgrade 0032_pipeline_timing
docker compose up -d
```

### 8.3 整库恢复（最后手段）

```bash
cd "$APP"
docker compose stop app
docker compose run --rm --no-deps \
  -v "$BACKUP_ROOT":/backups -v "$APP/scripts":/scripts:ro \
  --entrypoint /bin/bash app \
  /scripts/restore.sh /backups/linguatrek-backup-YYYYmmdd-HHMMSS.tar.gz --to /data --force
docker compose start app
sudo -u ln sqlite3 /srv/ln/data/app.db 'PRAGMA integrity_check;'  # 期望 ok
```
